| 诀 | 全句 | 出处（本轮实事） |
|:--|:--|:--|
| 一 | **先查总包，后动刀** | 我造 §P14「桌级靴长探针」之前未阅总包，事后发现 §R01-chk／§R01-inv／§R01-anm 早已在册，且 §R01-chk 之 Fisher-z CI 较我之点估计更严。§P14 遂成重复节。 |
| 二 | **校验器先自校** | 本轮四次伪命中：`grep $'\r'`（/bin/sh 不支持）、正则跨块贪吃、单引号格式串漏扫、保留字入定义集。**报错先疑器，不疑档。** |
| 三 | **同名必缀粒度** | 总包实测：`n_bets` 三义、`max_round` 三粒度（单键 `bet03` ／双键 ／三键含 `dt`）、`n_orders` 三式。缀 `_ts`／`_ms`／`_table`／`_uid`。 |
| 四 | **代理不得冒真值** | `MAX(round_no)` 是「观测到的最大局号」，非「靴有几局」。判级 OBSERVED·代理，禁建 `shoe_length = max_round`。 |
| 五 | **发现并列非解决并列** | `RANK()` 只报 tie，`ROW_NUMBER()` 仍任选一行。`dedup_integrity_ratio = 1` **不**证明版本选择确定。二闸须分家（G-2A 唯一性／G-2B 决胜确定性）。 |
| 六 | **诊断分母取未剔者** | 过滤与诊断同层，被剔者凭空消失，`n_null` 只能永报零——自证清白。故 `raw`（业务闸）→ `gated_struct`（键闸）→ `gated_member`（会员闸）三层。 |
| 七 | **观测非证明** | OBSERVED ≠ PROVEN。「一靴最多跨 2 日」系历史实测（§R01-0c），非业务不变量，故 `n_dt_shoe ≥ 3` 只能 **FLAG**，不能写「必为靴号重用」。 |
| 八 | **去分母非去耦合** | `corr(L, n_bets)` 只是**共享分母已移除**，业务生成关系仍在。判级 `OBSERVED_ASSOCIATION`，禁「影响／导致／效应」。 |
| 九 | **版本禁跳级** | 总包自订：只增新节 → MINOR（v11.1.0）；破表头契约 → MAJOR（v12.0.0），且须先经 v11.1.x。**故我署「v11.0.5 / C2」是错的。** |
| 十 | **跨行分支必入括号** | R 于括号深度 0 遇换行即断句，`else` 遂无所依附。凡跨行 `if/else` 必置于 `{ }` 或 `( )` 内。 |
| 十一 | **口径锁先于引用者** | `LATE_DEF` 立于下游节而上游节引用之，即「找不到对象」。全档最上游之契约，其定义位置必须先于一切引用者。 |
| 十二 | **未见原档不宣纳入** | 手上没有的文件，不能宣布已合并。「强化稿自身一致」≠「与总包全局一致」。 |
