# 一 不可违之铁律（十二条，永久生效）

## 1.1 标准与分级

**T × L × S 三轴，三者不得混称**：
`T` = 依据性质（T1 规范性／T2 科学性／T3 工程性／T4 业务性）
`L` = 核验领域（L1 数据真实性 … L9 决策治理，共九层约 95 项控制项）
`S` = 风险严重度（S1 致命·停止分析／S2 阻断·禁入正式结论／S3 条件／S4 建议）

**标准来源一律取全天下最顶尖者**，不以马来西亚或任何单一辖区为上限。
「该标准不适用于本辖区／本场景」**永不得**作为放宽之理由。
多标准并存取最严者；权衡后仍未决者，一律取严。

**三概念永久区分**：规范性标准（ISO/IEC、法规、监管原文）／最佳专业实践／本项目铁律。
**自拟规则永不得冒充国际标准。**

**红队八问**（凡见「世界顶尖」自动启动）：谁制定？原文为何？属何类？是否仍有效？
适用范围？有无更严或更新来源？有无反例？我们是在引用标准还是自订规则？

## 1.4 数值与呈表

**铁律第九条**：凡正文数字，**渲染时自表格本体现算，严禁硬编码**。

**呈表纪律**：表格一律 gt 或 kable，**禁用静态表与静态图**；图表一律可交互者。
过宽用 `scroll-x`、过长用 `scroll-y`，**禁止截列或截行——截断即隐藏证据**。

**首末抽样**：一律采 data.table 打印概念，行号栏印**实际行号**
（首段 `1:`、`2:`、`3:`；分隔列 `---`；末段 `N-2:`、`N-1:`、`N:`，千分位分隔），
使**总观测数一望即知**。严禁「首1／末1」之类相对标号。
副标题须现算总行数、总列数、省略行数与省略占比。0 行须单独出提示。

**截断认识论**：`LIMIT` 产生的是**样本，不是全集**；「未出现」不等于「不存在」。

## 1.6 统计门槛

**禁止手写 `n ≥ 30` 之类普适样本门槛**；须逐指标反解
`n_min = f(p₀, α, 半宽 h, 单双侧, 簇内相关 ρ, 设计效应)`，
并以有效样本量 `n_eff = n / (1+(m−1)ρ)` 校正。

**MDE 不得写死单一公式**；须依 estimand、结局分布族、分配方式、相关结构、
设计效应与检定力设定分别推导。

**`1/√n` 仅为「零效应且近似 i.i.d.」下之一阶方差基准**，不得当作普遍方差律。

**措辞纪律**：「与纯抽样噪声高度一致，不足以支持其为独立证据」可写；
「完全可由抽样方差解释」「已判伪不存在真实异质性」**不可写**。

**阈值参数本身亦须经选参流程**：探索分布 → 候选集 → 训练期选参 → Purged Walk-forward
→ 样本外稳定性 → FDR／CI／效应量 → 审核容量 → Shadow → Gold Label → 经济门槛 → 生产。
