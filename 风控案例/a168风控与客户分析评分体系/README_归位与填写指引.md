## 三、闸门声明矩阵 · 填写指引

### 3.1 该填什么

母版（`scaffold`）**只读**，勿动；请填 `filled_v1.csv`。表内前 15 列是**机器观测之事实**（有／缺），
不必修改；只需填最后四列：

| 列 | 填法 |
|---|---|
| `豁免理由(人工填写·必填)` | 逐个被豁免的 Gate 写明理由。**理由须点名该 Gate 的关键词**（如 `rn`、`age022`、`bet38`），否则检查器不予采认，仍判 FAIL |
| `定谳(PASS/FAIL/WAIVER_DECLARED)` | 您的最终裁定 |
| `填写人` / `日期` | 留痕 |

`filled_v1.csv` 第 2 行是**示例行**，示范格式；**填毕请整行删除**（不删亦可，检查器会因其锚行为空而自动跳过）。

### 3.2 铁律三条

1. **Gate 缺失 ≠ Gate FAIL。** 现有「缺口数」是 raw gate coverage，是事实，不是缺陷分布。
2. **WAIVED 不得由机器推定。** 无人工理由者一律 FAIL——此约束已写死在检查器里。
3. **不得为求整齐而一刀切补闸。** 典型反例：`P01C_split_by_dim` 之检验对象即「语义是否随版本切换」，
   机械补 `rn=1` 会摧毁被检对象本身；应双轨保留（RAW 版本层＋DEDUP 业务层）。

### 3.3 优先填这 14 条（GMv1-14，缺口无正当豁免余地）

`P0C04`、`P0C05`、`P0C06`、`P0C09`、`TL08`、`TL10`、`TL11`、`TL11c`、
`P01D`、`P01E`、`P02C`、`K01b_seed_goldip`、`V_ipmatch`、`TL14`

> ⚠ **撞数陷阱**：本清单为 `GMv1-14`（指纹 `f8429826b52c`），

## 四、检查器用法

```
python 审计/工具/a168_declaration_vs_code_validator_v1.py ^
       a168_取数与核验_SQL总包_v10.sql ^
       审计/矩阵/a168_v10_闸门声明矩阵_filled_v1.csv ^
       审计/矩阵/判定结果_v1.csv
```
（Windows 用 `^` 续行；Linux／macOS 用 `\`）

运行前自动做两件事：**正则自验**（失败即拒跑）与**六元组自报**。
输出四态：`PASS` ／ `WAIVER_DECLARED` ／ `FAIL` ／ `DECLARATION_MISMATCH`。
`DECLARATION_MISMATCH` 优先于其余——声明与代码不符时，**二者皆不得默认为准**，须先厘清孰错。

未填状态下试跑基线：**PASS 423 ／ WAIVER 0 ／ FAIL 270 ／ MISMATCH 0**（共 63 条 × 11 Gate ＝ 693 格）。

## 四之二、Namespace Gate（交付集合身份之机械化保护）

```
python 审计/工具/a168_namespace_gate_v1.py . 审计/登记/a168_集合身份登记_v1.json v10-93
```

比对「`数据库/` 里的东西」与「登记册里的集合」是否同一集合，出四态：

| 态 | 含义 | 处置 |
|---|---|---|
| `IN_SET` | 登记有、盘上有 | 正常 |
| `MISSING` | 登记有、盘上无 | 交付件缺失（未导出／被删／改名） |
| `UNREGISTERED` | 盘上有、登记无 | NON_DELIVERY_ARTIFACT，须移出 |
| `NAMESPACE_LEAK` | 登记名现于 `数据库/` 之外 | 命名空间泄漏 |

集合一致则退出码 0，否则 1（可挂 CI／pre-commit）。
基数相同而集合相异时，额外印出**撞数陷阱**警示。

## 五、编码陷阱

矩阵 CSV 为 **UTF-8 with BOM**。中文版 Excel「另存为 CSV」可能改写为 GBK，
即 `S05_member_month_panel.csv` 之同型陷阱。回传前请确认仍为 UTF-8；
或直接以 Positron／RStudio 编辑：

```r
m <- readr::read_csv("审计/矩阵/a168_v10_闸门声明矩阵_filled_v1.csv",
                     locale = readr::locale(encoding = "UTF-8"))
readr::write_excel_csv(m, "审计/矩阵/a168_v10_闸门声明矩阵_filled_v1.csv")
```
