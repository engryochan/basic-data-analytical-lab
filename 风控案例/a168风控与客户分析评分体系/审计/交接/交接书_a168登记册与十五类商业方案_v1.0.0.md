## 四、怎么跑

```bash
# 项目根 = 风控案例/a168风控与客户分析评分体系
# 1) 重生十五份 qmd（登记册或模板或配置册改动后必跑）
Rscript -e 'source("函数/build_typology_reports.R"); build_typology_reports()'

# 2) 渲染（亦可双击 分析/风险会员商业方案/渲染_十五类.bat）
cd 分析/风险会员商业方案 && for f in *.qmd; do quarto render "$f" --to html; done

# 3) 模板自检（模板可独立预览，取登记册首类作样例）
cd 模板 && quarto render 风险会员商业方案_模板.qmd --to html
```

环境：R 4.6.1（`C:\Program Files\R\R-4.6.1\bin\Rscript.exe`）· Quarto 内嵌于 RStudio
（`C:\Program Files\RStudio\resources\app\bin\quarto\bin\quarto.exe`）· 包：yaml/data.table/knitr/digest。

**工作目录**：模板与十五份皆自所在处**逐级上溯**、命中同时含 `规范/` 与 `函数/` 者为根，
故于 `模板/`（一级）与 `分析/风险会员商业方案/`（二级）两处皆可直接渲染。

## 六、埋雷与已知坑（接手者请先读这节）

| 坑 | 症状 | 已做的防护 |
|---|---|---|
| **R yaml 静默丢键** | 以 `null`/`NULL` 起头、后接非 ASCII 之未加引号键名，解析后键名消失且**不报错** | `migrate_registry_v1_5_0.R` 之 `.quote_lossy_keys()` ＋ SR-8 零丢键闸 |
| **`..var` 置于 data.table 的 `i` 位** | 恒报「找不到对象」；`registry_typology()` 曾因此**从未被成功调用过** | 已改为局部变量 `.tid` |
| **`format()` 遇时间字符串** | 试解为 POSIXlt 而抛「字符串的格式不足标准明确」 | 改 `as.character()` |
| **`v == ""` 于 POSIXct 列** | 空串被强制解为时间而抛错 | 先判 `is.character(v)` |
| **列名含 `day`/`month` 之计数列** | `n_days`／`tenure_months` 被误判为时间轴 | 改为**取值形似日期之实证判定**，并另列「疑似计数列」 |
| **`fifelse` 类型不合** | `threshold` 列全空时被 fread 读成 integer | 一律 `as.character()` 后再比 |
| **顶层 `else` 另起一行** | knitr 解析为新语句而报「意外的 else」 | 一律用 `{}` 包住 |
| **GBK 交付件** | `S01_player_score.csv`／`S05_member_month_panel.csv` 实测为 GBK | `tr_load()` 自动回退解码 |
| **巨档** | `R03b_player_dealer_daily.csv` 2.2 GB | 逾 300 MB 只读前 150 万行并标 SAMPLED |

## 七、不可动摇的纪律（写给下一手）

1. **禁硬写**：任何计数、阈值、分位、门槛——取登记册或配置册，不得写死于 qmd 或代码。
2. **禁跨层滑移**：`OBSERVED ≠ LABEL_VALIDATED ≠ CAUSALLY_ESTABLISHED ≠ ADMITTED_TO_RISK_DECISION`，逐层独立举证。
3. **禁以文字冒充结果**：缺档、缺列、缺时间轴——一律登记「待表」，不得以静态文字替代（铁律第九条）。
4. **T-03 四禁令**：`ranking`／`scoring`／`trigger`／`enforcement` 全 `FALSE`，只可作画像字段；「调为 30 局后」不改其性质。
5. **措辞禁令**：五道铁门未全 PASS 前，禁出现「验证完成」「模型成立」「统计生产就绪」「风险模型上线」「已证明」「确认作弊」。
6. **SEARCH 不得篡改规则册**：人工查询命中与正式规则命中共用同一 `risk_alert`，以 `trigger_source` 区分。
7. **单份手改视为漂移**：十五份任一手改，下次跑生成器即被覆盖；要改就改模板或配置册。
