## 二、先生之问：是否需要最大回撤／索提诺／夏普？——**需要，但不在先生所设想之处**

### 2.1 平台层实测（`P12a_platform_daily`，139 日；Σ毛利 234,152,957 逐位对账平台账）

| 量 | 值 |
|---|---:|
| 日毛利均值 | 1,684,554 |
| 日毛利标准差 | 658,191 |
| **下行偏差** | **10,399** |
| Sharpe（日） | 2.5594（年化 ×√139 = **30.17**） |
| **Sortino（日，MAR=0）** | **161.99** |
| **最大回撤** | **−121,578（仅占累计 0.0519%）**，谷底第 124 日 |
| 负毛利日 | **2 / 139（1.44%）** |
| hold 日率 | 均 1.9384%，sd 0.6900 pp，最差 −0.1393%，最佳 3.2944% |
| 30 日滚动 hold sd | 中位 0.6690 pp，最大 0.8309 pp |

⇒ **平台层：算得出，却几无判别力。** 庄家优势使回撤近乎不存在（139 日仅 2 个负日，MDD 占累计万分之五点二）。**恒不变之量无从区分处置之优劣**——以之比较处置方案，一律得「无差异」。

### 2.2 会员层实测（`P_player_month`，723,442 人 × 6 月）

| 量 | 值 |
|---|---:|
| 活跃 ≥3 月者 | 73,634（10.2%） |
| **活跃 ≥5 月者** | **21,475（2.97%）** |
| ≥5 月者之 Sortino 中位 | 0.483 |
| Sortino 与总 NGR 之 Spearman | 0.8081（同期，非预测） |
| **前 3 月 Sortino → 后 3 月 NGR** | **Spearman 0.0490** |
| 对照：**前 3 月洗码 → 后 3 月 NGR** | **Spearman 0.4197** |

⇒ **会员层：三指标不可用。** 97% 之会员根本无足够长之序列可算；纵可算者，Sortino 之预测力（0.049）**不足敞口之九分之一**（0.4197）。以之定赏罚，属以噪声定人命运，且违 P-15／P-16。

### 2.3 ⚠ 现有之「索提诺稳定性」已是废栏，而它**已是 T-07 之登记判据**

`S01_player_score.索提诺稳定性` 实测：NA **156,343**（21.6%）· 中位数 **−1**（下限堆积）· 最大 9.458e11 · 与 `profit` 之 Spearman **−0.0423**（近零）· 与 `valid_bet` 之 Spearman **0.6089**。

⇒ 名为索提诺，实为**敞口代理**，且带 −1 之退化下限与近四分之一缺失。此栏现列为 T-07 之判据列，须于 N-5 一并改判（建议降为 `PROFILE_ONLY` 或重定义）。

### 2.4 那么这三个指标该用在何处？——三处，且只此三处

**（一）用于处置【决策】，而非实体【评分】——此即先生所要之「将误判风险降至最低」之正解**

对每一处置手段算其**信息比**：`IR = ΔNGR / sd(ΔNGR)`，并算处置期间平台日 NGR 之 MDD 作最坏情形成本。
此为**对决策之风险调整**，非对会员之风险调整——故不违 P-15（不以全窗百分位定赏罚线）、不违 P-16（不以实现输赢符号定罚）。
所需之表：`PI01_treatment_delta_member`（会员级前后，含 `d_revenue`）＋ `PI02_treatment_delta_platform`（队列 × 期）＋ `TL10`／`TL11`／`TL14`（处置台账）＋ `P12c_member_daily_pnl`（日序列，供算 sd 与 MDD）。
⛔ 前置：PI-01a~d 四缺陷未修前，`d_revenue` 不得作经济结论（`ELSE 0` 令 46% 处置后无投注者之 `d_revenue = −ggr_pre`，为虚假巨额负数）。

**（二）用于桌台级与荷官级——此二者系营运单位，其收益波动本就是庄家该管的**

现盘无桌台／荷官之日序列。**而 #133 RK01_round_fact 正可产出**：其已带 `biz_date`、`table_id`、`shoe_key`、`dealer_id_min`、`ggr`、`validbet`，聚合至 `table × day` 或 `dealer × day` 即得序列，再算 MDD／Sortino／滚动 hold sd。
⇒ **这是 #133 之第二个用途，此前未言**。且此用途不涉会员赏罚，无 P-15／P-16 之虞。
⚠ 前置：须先排除 G3 十三张桌（900–913，占 33.2% 局数）之疑非真人者，否则荷官级方差分解被污染。

**（三）用于高额客群之敞口限额（风险管理，非赏罚）**

平台整体 MDD 微不足道，然顶 0.1%（723 人）占洗码 45.3%、占 NGR 31.4%。**该子群之日毛利方差远高于平台**，其 MDD 才是真正的资本风险，可用于设**限额**（风险管理），⛔ 不可用于定**罚**。
