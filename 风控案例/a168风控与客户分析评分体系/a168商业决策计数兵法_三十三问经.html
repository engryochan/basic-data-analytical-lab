2 序篇 · 立法：何谓三十三问法

孙子曰：兵者，国之大事，死生之地，存亡之道，不可不察也。 今以统计军械代兵，以平台盈亏代死生。察之之法，曰三十三问。

先生所颁之问式，其骨在三层递归，其肉在十一目。本书据此立法，永为定式：

三层（体·用·元）

  • 体：此事之标准为何。——问的是「它是什么」。
  • 用：该标准之优势、劣势、局限与漏洞何在。——问的是「用它会怎样」。
  • 元：判定上述优劣所依据的那把尺，其本身之优势、劣势、局限与漏洞何在。——问的是「凭什么这么判」。

第三层即是对红队本身的红队（Meta-RedTeam R4）。凡只答到第二层者， 本书一律判为「未过三十三问」，不得上阵。

十一目依次为：定义标准、使用标准、计算标准、阈值标准、计算阈值标准、用途、 越闸后果、越闸措施、越闸价值、越闸局限、越闸结论。

三十三问与外拟五十项之关系：骨与肉，非替代

外部曾拟一套五十项线性清单（模型名称 → 定义 → 标准四问 → 使用四问 → 计算四问 → 阈值四问 → 计算阈值四问 → 用途四问 → 后果与措施 → 商业价值四问 → 终判五问）。 本书裁定：二者并存不并轨。

  • 三十三问是递归审视法：其价值在第三层「元」——追问判定优劣所依之尺本身对不对。 线性清单没有这一层，故无法发现「用错的尺量出对的结论」这类错误。
  • 五十项是线性检查清单：其价值在穷尽度与可培训性，适合新人照单执行。
  • 两者之交集：五十项之第 03 至 45 项，可逐项落入三十三问某一格，无一遗漏。
  • 两者之差集：五十项之末五项（是否入生产／是否可作处罚依据／是否需 A/B／ 能否证明增量 NGR／红队裁决）是三十三问原本没有的—— 三十三问止于「结论」，未追问「结论之后动不动手」。此五项已采纳， 立为 小节 15 之终判五问，自 v1.2 起每卷必答。

故本书自 v1.2 起之定式为：

\[\text{每卷} \;=\; \underbrace{11 \times 3}_{\text{三十三问 · 查得对不对}} \;+\; \underbrace{5}_{\text{终判五问 · 答动不动手}} \;=\; 38\ \text{格}\]

\[\text{三十三问} \;=\; \underbrace{11}_{\text{目}} \times \underbrace{3}_{\text{层}}\]

3 正名篇 · 先正其名，而后可用

子曰：名不正则言不顺。军械之名不正，则闸门之判不服。

正名三事

  1. 索题诺率 → 索提诺率（Sortino Ratio）。先生手谕作「索题诺」， 父档《a168 风控与客户分层评分体系 · 商业方案》全篇作「索提诺」（经核实，正文出现 73 处）。 为维系血统一致，本书一律作 索提诺率，并在此备案通假，日后检索两写皆可命中。
  2. 索提诺「率」与「比率」。父档二者混用（「索提诺率」「索提诺比率」并见）。 本书统一作 索提诺率，其英文一律作 Sortino Ratio，不再另立别名。
  3. 「兵法」之实。本书为商业决策之判据书，非模型实现书。 模型如何算，归 SQL 总包与主方案；本书只答一件事—— 这件军械凭什么可以决定平台的钱怎么收、怎么放、怎么罚。

parse_radar <- function(path) {
  if (is.na(path) || !file.exists(path)) return(NULL)
  s <- paste(readLines(path, warn = FALSE, encoding = "UTF-8"), collapse = "\n")
  st <- gregexpr("Plotly.newPlot", s, fixed = TRUE)[[1]]
  if (st[1] == -1L) return(NULL)
  bnd <- c(st, nchar(s))
  ent <- c("玩家", "荷官", "代理", "风控专员")
  res <- list()
  for (i in seq_along(st)) {
    seg <- substr(s, bnd[i], bnd[i + 1L] - 1L)
    m <- regexpr("\"theta\":\\s*\\[[^]]*\\]", seg)
    if (m == -1L) next
    th <- regmatches(seg, m)
    th <- sub("^\"theta\":\\s*\\[", "", th)
    th <- sub("\\]$", "", th)
    d <- trimws(unlist(strsplit(th, ",")))
    d <- gsub("^\"|\"$", "", d)
    if (length(d) > 1L && d[1] == d[length(d)]) d <- d[-length(d)]
    nm <- if (i <= length(ent)) ent[i] else paste0("图", i)
    res[[nm]] <- d
  }
  ## 声明维数：自「四实体三十一维」段落窗口内现取
  pos <- regexpr("四实体三十一维", s)
  decl <- setNames(rep(NA_integer_, length(ent)), ent)
  if (pos > 0L) {
    win <- substr(s, pos, pos + 400L)
    for (e in ent) {
      mm <- regexpr(paste0(e, "\\s*([0-9]+)"), win)
      if (mm > 0L) {
        got <- regmatches(win, mm)
        decl[[e]] <- as.integer(gsub("[^0-9]", "", got))
      }
    }
  }
  list(dims = res, decl = decl, engine_plotly = length(st),
       engine_echarts = length(gregexpr("echarts", tolower(s), fixed = TRUE)[[1]][
         gregexpr("echarts", tolower(s), fixed = TRUE)[[1]] > 0]))
}

6 卷一 · 索提诺率

兵法曰：善守者藏于九地之下，善攻者动于九天之上。 赌客之中，善赢者藏于波动之内。索提诺率者，专照其无波之赢。

6.1 一、开宗明义：此一军械在赌场里是反着用的

在资产管理业，索提诺率高是好事——基金经理赢得稳，客户睡得着。 在赌场，索提诺率高是坏消息。

道理极浅：百家乐的庄家优势是一个恒定的小正数。 一名会员若在数百个下注日里几乎没有痛过一次， 其日盈亏序列的下行离差趋近于零，索提诺率便冲到全体的最右尾。 这不是运气好，这是收益结构不该长这样。

\[\text{Sortino} \;=\; \frac{\bar r - \text{MAR}}{\sigma^-}, \qquad \sigma^- \;=\; \sqrt{\frac{1}{T}\sum_{t=1}^{T}\min\!\left(r_t - \text{MAR},\, 0\right)^2}\]

其中 \(r_t\) 为该会员第 \(t\) 个下注日之剔返水 ROI，分母基数为 validbet 而非原始投注额； \(\text{MAR}=0\)，即以打平为界。

一句话给上司

夏普率问的是「他赢得多不多」；索提诺率问的是「他输的时候有多痛」。 在我们这一行，一个从来不痛的人，比一个赢很多的人更值得看一眼。 所以本方案把索提诺率放在玩家雷达的罚侧，而不是赏侧。

14.2 二、可采之三事

其一 · 终判五问，采纳并立为每卷必答

外部所拟五十项之末五项——是否入生产、是否可作处罚依据、是否需 A/B、能否证明增量 NGR、红队最终裁决—— 是本书三十三问原本没有的。三十三问止于「结论」，而未追问「结论之后该怎么办」。 故本书自 v1.2 起，每卷于三十三问之外加答终判五问，见 小节 15。

其二 · 各模型不共用同一套闸，采纳

此说与本方案既有之「各领域判罚不同」同源。故立逐模型主闸登记，见 小节 16。

其三 · CFA 之流动性限制，采纳为卷一新增局限

CFA 体系之绩效指标说明明载：此类指标最适用于在运作良好的资本市场中连续定价的流动性投资； 若施于非流动性定价之组合，因分母的风险度量被低估，其数值很可能被高估。 且此类指标通常以月度收益计算，并以乘以 \(\sqrt{12}\) 近似年化。

本方案之会员日 ROI 序列既非连续定价、亦非流动性资产、亦未年化。 故须新增一条卷一原无之局限：

\[\text{a168 之索提诺率} \;\xrightarrow{\ \text{分母系统性低估}\ }\; \text{数值系统性高估}\]

这条限制与本方案之判读方向叠加，后果加倍：我们把索提诺率放在罚侧—— 高即可疑。而该指标在本场景下天然偏高，等于把罚侧的门槛悄悄放低了。 故 T2 稳定性闸取 P99 这一极端分位是必要的，它同时在补偿这一层高估； 若日后有人以「P99 太严」为由下调分位，须先回答这条高估补偿了多少。

17 革命篇 · 总铁律：盈利传导链

兵法曰：不谋万世者，不足谋一时；不谋全局者，不足谋一域。 统计正确 ≠ 业务有效 ≠ 盈利有效。 此三者之间，隔着两道从未有人替我们跨过的坎。

任何一件军械，最终都必须走完这一条链，中途断在哪一环，其价值即止于哪一环：

\[\text{数据} \to \text{统计量／模型} \to \text{能力或风险证据} \to \text{闸} \to \text{业务动作} \to \text{处置} \to \text{玩家行为变化} \to \text{GGR} \to \text{NGR} \to \Delta\text{NGR} \to \Delta\text{NEV}\]

而真正值得老板签字的，只有最后一项：

\[\Delta \text{NEV} \;=\; \Delta \text{NGR} \;-\; \Delta \text{处置成本} \;-\; \Delta \text{复核成本} \;-\; \Delta \text{流失成本} \;-\; \Delta \text{技术成本}\]

三条不可混为一谈的口径

\[\Delta \text{GGR} \;\neq\; \Delta \text{NGR} \;\neq\; \Delta \text{NEV}\]

举例：某处置使 \(\Delta\text{GGR} = +100{,}000\)，看着漂亮。 扣去复核成本 20,000、流失成本 30,000、处置成本 15,000、技术成本 20,000， 真正落到公司口袋里的是 15,000 —— 只剩一成五。

拿博彩的话讲：这就像只报台面赢额不报返水、不报占成、不报人工。 台面赢一百万，月结可能只剩十五万。只报 GGR 的方案，本书一律判为不可上线。

21 多闸制 · 一个综合分为何危险

\[\text{多闸制} \;\neq\; \text{单一综合分}\]

本方案自身正踩在这条线上

本方案现行之合成算式为：

\[\text{综合分}_i \;=\; \frac{1}{|D^{+}|}\sum_{d \in D^{+}} v_{id} \;-\; \frac{1}{|D^{-}|}\sum_{d \in D^{-}} v_{id}\]

即赏侧均值减罚侧均值，得出一个数（例如 92）。 问题是：这个 92 里同时混着盈利能力、下注行为、持续性、异常性、资金行为、网络行为、 生命周期、代理关系、桌台行为九类完全不同的事。

九件事压成一个数，92 到底代表什么？不清楚。

而 v6.9 §32 已建成统一能力领域本体 D01–D12，多闸制所需之骨架其实已经在了—— 只差把「一个综合分」拆成「逐领域各设一闸」：
