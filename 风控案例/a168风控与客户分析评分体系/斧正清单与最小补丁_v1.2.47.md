### 补丁 P-08：分位可信性护栏（修 D-09）

`.qv()` 改为——**不设普适 n≥30 之类门槛**，改由分位本身反解最小样本量
（q 分位欲不退化为极值序统计量，须 n ≥ ⌈1/(1−q)⌉）：

```r
.qmin <- function(q) as.integer(ceiling(1 / (1 - q)))
.qv <- function(tb, cl) {
  v <- suppressWarnings(as.numeric(.tabs[[tb]][[cl]])); v <- v[is.finite(v)]
  qs <- vapply(c(0.5, 0.9, 0.99), function(q)
          if (length(v) < .qmin(q)) NA_real_ else
            stats::quantile(v, q, names = FALSE), numeric(1L))
  c(length(v), qs)
}
```

并于表内以「○ n 不足（须 ≥ N）」显示 `NA`，**禁以退化极值冒充分位**。
