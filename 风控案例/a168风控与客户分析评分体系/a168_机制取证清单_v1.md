## Phase 1 · 只读证物

### `MECH-E05` · 拼接结构取证（**建议首跑**）

**依据**：`6,143,388 = 61 × 100,000 + 43,388`；`DB62` ＝ 第 62 批。故 CSV 疑为分批拼接（INFERRED）。

**查**：

```
下载目录 / 工作目录 / 归档目录中，是否存在
  ① 形如 offset_0 / offset_100000 / … / offset_6100000 之中间批档
  ② 第 62 批之独立档案（其大小与 mtime 直接给出事件时点）
  ③ 拼接脚本（R / Python / shell）及其 stdout
  ④ 脚本中之批大小、总批数、失败重试逻辑、异常处理分支
```

**预注册判读**：

| 结果 | 可推出 | **不可**推出 |
|---|---|---|
| 中间批档存在，第 62 批档为 43,388 行 | 截断发生于**批 62 之取得或写入**；B/C/D/E 可就该批单独取证 | 「因此是宕机」 |
| 中间批档存在，第 62 批档为 100,000 行 | 截断发生于**拼接阶段**（F 枝显著升格） | 「因此拼接脚本有 bug」（须读脚本） |
| 中间批档已删，仅脚本在 | 脚本之批大小与重试逻辑可读 | 任何关于实际执行之结论 |
| 皆无 | — | **不得推出「非分批导出」**；只记 NO TRACE |

> **反向锁**：若查得 CSV 系**单次导出**（非拼接），则 `6,143,388 = 61×100,000 + 43,388` 降为**巧合**，本项作废，不得留作旁证。

### `MECH-E01` · 末行完整性

**先决**：测定该 CSV 之行尾体例。**依 `SC-002`：数 `\r` 字节，禁用 `$` 锚点。**

```r
f <- "<只读副本路径>"
n <- file.size(f)                       # 应为 2,206,612,719
con <- file(f, "rb"); seek(con, n - 8192)
tl <- readBin(con, "raw", 8192); close(con)

sum(tl == as.raw(0x0d))                 # \r 计数（尾段 8 KiB）
sum(tl == as.raw(0x0a))                 # \n 计数
tl[length(tl)]                          # 末字节
sum(tl == as.raw(0x00))                 # 空字节填充计数
cat(rawToChar(tl[(length(tl)-600):length(tl)]))   # 还原末两行
```

**分三格记录**：

| 格 | 问 | 现状 |
|---|---|---|
| `E01a` | 末行 24 字段是否完整 | 🟠 **已间接证实**（§七甲 边界比对之末行即此行，逐列一致）— INFERRED / INDIRECT。本测将其升为 OBSERVED / DIRECT |
| `E01b` | 末行之后是否有终止换行 | ⚪ |
| `E01c` | 换行之后是否有残缺字节 / `0x00` | ⚪ |

**预注册判读**：

| 结果 | 可推出 | **不可**推出 |
|---|---|---|
| 完整行 ＋ 终止换行 ＋ 尾部无残字节 | 文件呈现**正常之应用层行边界** | 「所以绝非宕机」——中断前可能已完整 flush 缓冲区 |
| 末行字段残缺 或 无终止换行 | 存在**流中断之直接痕迹**；D/E 枝升格 | 「所以是电脑宕机」——中断层级未定 |
| 尾部存在 `0x00` 填充 | 存在**文件系统级写入异常**痕迹 | 任何关于起因之结论 |

> **双向锁（照录裁示）**：**完整尾行 ≠ 排除宕机；残缺尾行 ≠ 证明宕机。** 本项为机制**辨别**证据，非因果证据。

### `MECH-E02` · 切点语义与集合事实

**切点固定为字符串形**：`(dt='2026-05-06', member_id='145011639', dealer_id='2256')`
**禁用数值比较**——`DR-LOAD-002` 已将 `dealer_id` 退出数值化名单（抹前导零）。

**测两问**：

```
Q1  CSV 中 05-06 之 member_id='145011639' 的 dealer_id 集合
Q2  Layer B 中同日同会员之 dealer_id 集合
    → Q1 ⊊ Q2 ?
```

**预注册判读**：

| 结果 | 定 `12,685 / 12,686` | 定终止点性质 |
|---|---|---|
| `Q1 ⊊ Q2`（该会员两侧皆现） | **12,686** — 戊之两比值改 6.023 / 31.730 | 切点落于**会员内部**，不对应任何语义边界 |
| `Q1 = Q2`（该会员在 CSV 内完结） | **12,685** — 戊之原值成立 | 切点恰落于**会员边界** |

**已预先锁定，不因结果改口**：

- 戊之**定性结论「两降一升 → 末桶不可用任一单一比例缩放」在两值下皆成立**，不因本测回收。
- 「切在会员内部」**支持**「任意行截断」之**形态**解释，**不等于**证明电脑宕机（`SC-013`：以形状代机制）。
- 无论结果为何，`SC-023` 之定性（12,685 系减法推得，不得冒充已验证集合基数）**不撤销**。本测只补末位。

### `MECH-E04` · 对应段字节同源性

**三级比对，令 UNEQUAL 可立即定位**：

| 级 | 比什么 | 差异指向 |
|---|---|---|
| L1 | `CSV[6,100,001:6,143,388]` 原始字节数 vs `DB62[1:43,388]` 原始字节数 | 总体 |
| L2 | 行尾归一化后（统一 LF）之字节数 | 若 L1≠ 而 L2＝ → 纯行尾差异 |
| L3 | 逐列 as-character 之字符串完全相同率 | 定位到具体列 |

**已知参考量**（供预期，不作结论）：

```
主 CSV  均行 ≈ 359.19 B      （2,206,612,719 ÷ 6,143,388）
DB62    均行 =  384.25 B      （   38,424,595 ÷    100,000）
差                +6.98%
```

**预注册判读**：

| 结果 | 可推出 | **不可**推出 |
|---|---|---|
| L1 EQUAL | 两 artifact 之序列化字节表现相同 | 「同一次导出」 |
| L1 UNEQUAL | 两 artifact 之**序列化字节表现不同** | **「二者非同一导出路径」**——须先逐一排查下列成因 |

**UNEQUAL 后之成因清单（须逐项排除，不得跳步）**：
格式化 · 数字精度 · NULL 表示 · 引号策略 · CRLF/LF · 编码 · 字段类型转换 · 导出器版本

> 与 `SC-016`（`0E-7` vs `0`、17→15 位）、`SC-018`（容差型数据不适用精确 join）**属值得关联调查之形态**，但**不得一步跳成「不同导出路径」**。
