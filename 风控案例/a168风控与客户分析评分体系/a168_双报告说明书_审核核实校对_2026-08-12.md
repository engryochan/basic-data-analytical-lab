### 三条术语纪律（全文强制）

1. **产品 ≠ 玩法**：产品指平台推出、供玩家投注的标的（`bet02` 大类、`bet09` 投注产品）；

3. **GGR ≠ 营业额**：GGR 为赌场毛利（客人 `game_pnl` 取负号汇总）。

## 3.1 五条导出判准（本轮由 SQL 总包卷首与各条声明归纳）

> **补充判准（报告侧）**：读入前后行三重核验——存在性、表头（契约必需列）、内容指纹。

## 3.4 报告侧的对接：契约、占位与体检

- **`CONTRACT`**（主方案 R 侧）：逐份登记 `sql` 编号与 `cols` 必需列，
  必需列缺一即判「表头不符」，**比运行到一半才 object not found 早得多**。
- **`NEED` + `PH_LABELS`**：21 个占位标签逐一登记所待文件；
  渲染时断言「凡进入 `ph_out()` 的标签必须在 `NEED` 有登记」，缺登记即控制台点名。
- **`need_data()` 前置校验**：三层检查（对象是否 NULL / 是否空表 / 列名是否齐全），
  防护责任由代码自身承担，**不外包给 chunk 选项 `eval:`**——
  控制台逐段粘贴时 chunk 选项完全失效。
- **编码自适应读取**：UTF-8-sig → UTF-8 → GB18030 → GBK → Big5 → Latin1，
  并在日志注明用了哪一种。
- **指纹缓存**：内容寻址（输入内容哈希 + 全部参数 + 算法版本号），
  三者任一变化即重算；**只看 mtime 两头都错**。

## 3.5 这一层的价值与所得结论

1. **「导什么」本身就是一项方法论判断**。判准之二（屏幕可裁者不导）省下的不是磁盘，
   是**读者的注意力与审计成本**——凡进「数据库/」者皆被视为结论承重物。
2. **文件名冲突是最隐蔽的失败**。两组曾各自同写一个 CSV，后跑者覆盖先跑者，
   使对打对名单清空、风控员雷达退化为结构演示，**全程不报错**。
   故「一份文件名只允许一条活跃语句」这条纪律的价值高于其字面。
3. **导出上限即结论边界**：受 1,000 行截断者，只承认「排序头部」结论，
   **任何「未出现」类判断在截断导出上一律无效**。

   `n_member ≥ 20` 之 IP 至少上千个（P50=34，榜首 `138.84.109.251` 达 2,132）。
   故「20 账户」不能单独作阈值，须与结构指标组合。
2. **最小多少订单才算有效关联？** **n ≥ 30**（Wilson 95% CI 宽度 ≤ 0.15 准则），
   与尾秒侧同一标准；D-06 实测该过滤生效（`min n_rounds_all` 恰为 30）。
3. **该 IP 盈利与全平台盈利如何比？** **必须用剔返水之版本 C**。
   庄闲对押理论损耗为总流水 1.147%，C-01 Top20 IP 之 `game_pnl/stake` 中位数
   实测 **−1.12%，与理论值几乎重合**——资金以近似完美对冲方式流转；
   会员层必亏（净 EV −0.247%），**利润在代理链层**。版本 A/B 会被返水制造伪盈利。
4/5. **各比例档命中与工作量？** 两阶段网格已立，L0 一票否决 17 IP 就位；
   **饱和段（CGNAT）967/1000 必须先剔除**，否则命中数被基础设施污染。
6. **跨月是否稳定？** 已实测到比跨月更强之形态——**跨 IP 稳定**：
   42 对会员在多个 IP 上反复完美对押，榜首一对横跨 **22 个 IP**、另一对 **1,185 局全反向**。
   换 IP 不换搭档，是比「换月不换行为」更难伪装的持续性证据。

**§2.2 尾秒八问**

1. **开局／封盘／时长能否取得？** **封盘不可得，已定案**（`game_info` 仅两个时间字段）。
2. **下注集中在第几秒？** 「第 N 秒」类绝对表述**全部作废**。全局仅 7.25% 订单落在 [29,31] 秒；
   30 桌进度 P99 跨桌 0.43~0.73，桌间异质性大到任何全局秒阈值都会快桌误杀、慢桌漏判。
3. **各秒段 ROI 差异？** 末段 ROI 描述性偏好 +1.77pp，但被投注选项构成解释；
   D-03X 分层显示该差随佣金模式**符号翻转**（辛普森结构），聚合差无稳定承载体。
4. **第 29 秒是真异常还是基准如此？** **基准如此**。五重检验不一致
   （t p=0.0356 / NW p=0.0135 / BCa 不跨零 **但**符号检验 78/139 天 p=0.1745），
   Bonferroni 30 项校正后不存活；BCa 下界经济量级 46.6 万 ≈ GGR 之 0.04%。
5. **多少局数才稳定？** **n ≥ 30**（Wilson CI 宽度 ≤ 0.15）。
6. **占比多少算持续性？** 观察档 ≥ 0.47（P90）、强档 ≥ 0.70（P99）；
   实测 P50=20.5%、≥50% 者仅 8.4%、纯尾段玩家 12 人。
7. **胜率／胜率差门槛？** **不存在自然门槛**——个体层 `winrate_diff > 0` 仅 49.7%（491/988），
   分布关于零对称。只能用分位法，**禁止绝对胜率差门槛入规则**。
8. **正常亏尾秒赢 + 跨月？** 强特征专项已立（`@sec-strong`），只作画像不作处罚。

**由此得出之总裁定**：尾注线**判定不成立、保持现状**；该线一切导出只为存档与画像。
此即精要报告开篇「已主动否掉一个看似有利可图的策略」之所指——
**不因均值好看而硬留**，是本方案方法论诚实性的最强证据。

# 五 第四问 · 以什么标准使用统计模型：判准、分类、评估与结论

## 5.1 选型五判准

1. **每一件方法必须绑定一个具体问题**，不做方法堆砌（军械库开宗明义）。
2. **阈值不得手拍**：一切阈值或由数据现算，或引用外部权威基准**并标出处**；
   「分界不在能不能算，而在该不该由我们算」。
3. **评估必须净化**：一切折级结果走 purged walk-forward + embargo，
   且同一物理局横跨切点者整局剔除。
4. **小样本必须收缩**：荷官／代理评分一律经贝叶斯（EB）收缩，
   否则「排在最前面的永远是小样本」——那是统计噪声，不是风险。
5. **可解释性优先于精度**：凡不能向风控专员讲清「为什么是他」者，
   不得作为处置依据，只能作排序参考。

| 题型 | 主尺 | 配尺 | 禁用 |
|---|---|---|---|

| 聚合层（十分位组／实体级） | **RelAE**（先聚合后取绝对值） | WAPE、Bias | 冒名「MASE」 |
| 对外汇报 | **WAPE**（差了几成） | Bias 指方向 | — |
| 判别 | AUC、Precision@K、Lift、校准 | 折间波动 | MASE |
| 生存 | C-index、时依 AUC | — | MASE |
| 经济评估 | 增量 GGR／NGR、ROI | 自助区间 | MASE |

**三条须并读之实测约束**：

1. **会员级 MASE 可算率仅约 9.8%**——禁运 7 日后目标零值率高达 83.4%，
   朴素外推分母为零者无从相除。故会员级 MASE 只能作高流水层附报，不可作总体刻度。
2. **RelMAE 单看有陷阱**：分母是朴素基准之误差，**朴素越烂此数越好看**，
   须与 WAPE、Bias 并读。
3. **Bias 不可省**：RelMAE 与 WAPE 皆取绝对值，会把系统性高估与低估一并抹平；
   某组若长期高估盈利，赏罚幅度即长期给多——**只有此尺看得出来**。

## 5.8 统计模型层之结论

1. **模型不是瓶颈，标的才是**。个体毛利率两期自相关仅 **0.112**，
   当前模型 Spearman 约 0.20 已达其 **189%**——预测能力已逼近物理上限，
   继续调参无收益。资源应转向**留存**与**毛利率**两个新标的。
2. **集成已被否定**：ρ(ET,GBDT)=0.996、ρ(ET,Bayes)=0.993，
   各模型在同一批个案上同时失手，集成不产生新信息。
3. **秩持续性 Jaccard 仅 0.02**，故只作**群体分层**，
   不作个体长期价值承诺（罚侧证据链不受此限）。
4. **经济分母已立**：$m_i > \rho/(1-\kappa_{share}) = 2.59\%$ 方为净贡献为正；
   低于此线者流水越大平台越亏。**须记：低于门槛 ≠ 该罚**，罚侧仍以证据链为准。
5. **赏侧结构性关闭**：$\gamma^* = m - \rho - \kappa = -0.091\%$
   （κ 取 `agent_dtl.ag012`，经 14,112 对父子层级单调性检验确证；ρ 取 `ag003` = 0.349%）。
   此非暂缓，是**结构性的没有**；欲改变须调降代理占成率或提高毛利率，皆属商务决策。
6. **灰度至少一个季度，不是四周**：净赢重尾（CV 约 8），主指标须缩尾 1%/99%
   或改净赢率（方差削减约八成），随机化到**玩家**而非代理线，
   样本累积约 8 个滚动折（约 16 周）方能把 MDE 压到 20%。
