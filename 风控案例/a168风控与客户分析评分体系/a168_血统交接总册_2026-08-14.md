## 六、四道已立的工程闸（勿擅拆）

| 闸 | 解何病 |
|---|---|
| **编码闸** `u8()`／`ok_utf8()` | `fread(encoding="UTF-8")` 遇 GB18030 会把原始字节原样标为 UTF-8，产出非法字节而非 U+FFFD，旧判据检不出。判据须用 `validUTF8()`，且先侦表头再读正文 |
| **呈现体量闸** `DT_MAX`／`GLOSS_MAX`／`PLOT_MAX`／`thin()` | 超量表全量落盘 CSV、页面呈首末（**分流非截断**，路径登记于 @sec-perf） |
| **依赖登记闸** `DEPS` | asis 块中 `print()` widget 不登记 `htmlDependency`，故 plotly.js／echarts.js 从未内联——div 与 JSON 俱在而引擎缺席 |
| **两清单对齐哨** `.miss` | `PKG_NEED` 与 `PKG_USE` 不对齐即自补占位并点名，不中断渲染 |

**雷达图**已改用 [F] 精要报告之 `er_radar()` 原码（连同 `w_`／`radar_txt`／`er_dep`／`er_id`／`EJ`／`er_ttl` 七件）。
其直出 HTML+JS、以 `cat()` 输出，**不经 `knit_print` 登记**，故不受 widget 依赖问题影响。
