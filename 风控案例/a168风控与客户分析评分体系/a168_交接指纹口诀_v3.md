**释（v3 新增九句）**：

7. **先页后档，先轮后源** —— 未取全页即不得判格；未定轮次即不得指来源。
8. **批号不认轮** —— 高批号非 08-12 独有（第 1、4、7 轮皆达高位）；中间档归属须以 **mtime 落于哪一轮区间**判定。
9. **mtime 要联证** —— `mtime` 只证最后写入时刻，不证内容来源。SQL 文本相同亦只是旁证。
10. **NO TRACE 不等无事件** —— 日志无记录 ≠ 事件未发生。`count=0` 之请求连 NO_TRACE 都不算。
11. **STOP 不等失败** —— Superset 之 `stopped` 多为人工中止后立即重发；重跑亦不证明曾失败。
12. **批六一两次成功** —— `OFFSET 6,100,000` 于 08-11（id=3127）与 08-12（id=3518）皆 success，**查询层已封口**。
13. **DB62 属八月十五** —— OFFSET / rows / SQL / 时序四项吻合，为 METHOD ARTIFACT。
14. **E05 未闭不读业务** —— 冻结序不得跳。
15. **降级亦是越级** —— 已 OBSERVED 之格不得无故退回 PENDING；低估比高估更隐蔽，且日后必被人「重新升级」。

## 三、体例（沿用，不得另立）

- **三十三问法**：十一目 × 三层（体·用·元）。第三层是对红队本身的红队。
- **终判五问**：是否入生产／可否作处罚依据／是否需 A/B／能否证明增量 NGR／红队裁决。
- **每卷定式** = 11×3 + 5 = **38 格**；六十项母标准为其肉（`@sec-t60`）。
- **三轴**：T（T1–T4）× L（L1–L9）× S（S1–S4）。
- **证据等级**：E0–E7。**本方案现最高 E3。**
- **可信度判据**：木桶取 `min`，不取加权平均。
- **四层契约**：A 表单 / B 数据库 NOT NULL / C 事件成立 / D 因果可用，**允许互不相等**。
- **Evidence Grade 与 Gate 分离**：`E5 + Density FAIL` 可并存，不得以前者绕后者。
- **星级评定**：不得自述，须由「已闭环闸 ÷ 已登记闸」派生（分母须先去重，见 `SC-024`）。
- **三级证据分层**（v3 新立）：`COLLECTED` → `HASHED` → `COPY-INTERNAL VERIFIED` → `SOURCE-IDENTICAL VERIFIED`。**工具自报成功 ≠ VERIFIED。**
- **SC / MECH / LEAD 分册**（v3 新立）：`SC` ＝ 已证实之我方错误；`MECH` ＝ 未证实之机制候选；`LEAD` ＝ 不足以成假设之片段。**互不倒灌。**
