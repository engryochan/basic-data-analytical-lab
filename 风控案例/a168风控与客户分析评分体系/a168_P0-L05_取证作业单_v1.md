# a168 · Phase 0 首刀 · `P0-L05` 取证作业单 · v1

```
对象   Windows Event Viewer / .evtx  ＋ 内存转储 ＋ WER 报告
目的   固化 2026-08-08 ～ 2026-08-15 之原始事件记录
性质   只读采集
禁止   解释 · 先验关键词筛选 · 筛后删除 · 修改原日志 · 清除日志 · 调整日志大小策略
输出   原始导出档 ＋ SHA-256 ＋ 采集时间 ＋ 文件大小 ＋ 环境记录
状态   ⚪ 待实测 → OBSERVED / PARTIAL / NO_TRACE / COLLECTION_FAILED
```

> **本作业单零结论。** 每一步只产生记录，不产生判断。
> **`Kernel-Power 41` 命中 ≠ 宕机原因**：只可记 `OBSERVED: unexpected shutdown/restart event`，不得写 `CAUSE = computer crash`。

## 一、Step 1 · 环境与时区记录（**须最先跑，且落档**）

```powershell
# 时区是全案对时之基准，缺之则 08-12 17:30:20 无法与事件日志对齐
Get-TimeZone | Format-List *
[System.TimeZoneInfo]::Local.BaseUtcOffset
"LOCAL_NOW  = " + (Get-Date).ToString('o')
"UTC_NOW    = " + (Get-Date).ToUniversalTime().ToString('o')
```

> **⚠️ 对时陷阱**：`.evtx` 内部以 UTC 存储，Event Viewer 以本机时区显示；而 §七甲 所记之 `2026-08-12 17:30:20`（Superset 执行时点）**究竟是本机时区、服务器时区抑或 UTC，目前 ⚪ UNKNOWN**。
> **在该时点之时区确定之前，不得将其与任何事件时间直接并列比对。** 此格独立立项，待 `L01` 解决。

## 二、Step 2 · 保留窗边界测定（**决定性，先于导出**）

```powershell
foreach ($log in 'System','Application') {
  "=== $log ==="
  wevtutil gli $log                      # 记录数 / 文件大小 / 最旧记录号
  wevtutil gl  $log                       # maxSize / retention 策略
  Get-WinEvent -LogName $log -Oldest -MaxEvents 1 |
    Select-Object TimeCreated, Id, ProviderName   # ← 最旧一条之时间戳
  Get-WinEvent -LogName $log -MaxEvents 1 |
    Select-Object TimeCreated, Id, ProviderName   # ← 最新一条
}
```

### 预注册判读（结果含义已写死，事后不得改）

| 最旧事件时间 | 记 | **不可**推出 |
|---|---|---|
| ≤ 2026-08-08 | 🟢 事件窗**完整保留** → 续行 Step 3 | 尚不含任何原因判断 |
| 落于 08-08 ～ 08-12 之间 | 🟡 **PARTIAL** — 须记明确切边界，可用范围随之缩小 | 不得以部分窗充作全窗 |
| > 2026-08-12 | 🔴 **NO_TRACE (L05)** — 目标窗已被滚动覆盖 | **不得推出「未曾发生宕机」**；只证日志已失，不证事件未发生 |
| 命令报错 / 权限不足 | ⚫ **COLLECTION_FAILED** | **不得记为 NO_TRACE**——二者判然有别 |

> **无论上表落于哪一格，Step 4（内存转储与 WER）皆须照跑**，其保留策略与 `.evtx` 相互独立。

## 三、Step 3 · 整频道导出（**不加任何筛选条件**）

```powershell
$CH = @(
  'System',
  'Application',
  'Microsoft-Windows-Kernel-EventTracing/Admin',
  'Microsoft-Windows-Kernel-Boot/Operational',
  'Microsoft-Windows-Ntfs/Operational',
  'Microsoft-Windows-StorageSpaces-Driver/Operational',
  'Microsoft-Windows-Diagnostics-Performance/Operational',
  'Microsoft-Windows-WER-Diagnostics/Operational',
  'Microsoft-Windows-Storage-Storport/Operational'
)

foreach ($c in $CH) {
  $safe = ($c -replace '[\\/]', '_')
  $dst  = Join-Path $OUT "$safe.evtx"
  try {
    wevtutil epl "$c" "$dst"
    "{0,-60} EXPORTED" -f $c
  } catch {
    "{0,-60} MISSING_OR_FAILED : {1}" -f $c, $_.Exception.Message
  }
}
```

**频道与来源之别（须记明，勿逐个尝试导出）**：

| 裁示所列 | 实为 | 落于 |
|---|---|---|
| `System` / `Application` | **频道** | 直接导出 |
| `Kernel-Power` | 来源 | `System` 频道内 |
| `Service Control Manager` | 来源 | `System` 频道内 |
| `Disk` / `Ntfs` / `StorPort` | 来源 | `System` 频道内（另有 Operational 频道，已列入上表） |
| `Windows Error Reporting` | 来源 ＋ 独立报告目录 | `Application` 频道 ＋ Step 4 |

> **来源之筛选一律留至 `L05` 判读阶段**，且只对已落档之副本操作，不回原处取数。

## 四、Step 4 · 附带证物：内存转储与 WER 报告

**内存转储 = 宕机之遗骸本体，证据强度高于事件日志中之一条记录。**

```powershell
# 小型转储（每次 BugCheck 一份，含时间戳）
Get-ChildItem 'C:\Windows\Minidump\*.dmp' -ErrorAction SilentlyContinue |
  Select-Object Name, Length, CreationTime, LastWriteTime

# 完整转储（仅保留最近一次）
Get-Item 'C:\Windows\MEMORY.DMP' -ErrorAction SilentlyContinue |
  Select-Object Name, Length, CreationTime, LastWriteTime

# WER 报告：应用程序崩溃之档案，含进程名与时刻
Get-ChildItem "$env:ProgramData\Microsoft\Windows\WER\ReportArchive" -Recurse -ErrorAction SilentlyContinue |
  Select-Object FullName, Length, LastWriteTime
Get-ChildItem "$env:ProgramData\Microsoft\Windows\WER\ReportQueue"   -Recurse -ErrorAction SilentlyContinue |
  Select-Object FullName, Length, LastWriteTime
```

**命中后立即复制入 `$OUT`，勿只记清单。**

### 预注册判读

| 结果 | 记 | **不可**推出 |
|---|---|---|
| Minidump 存在，时间落于 08-12 17:30 ～ 21:04 | 🟠 **该窗内确有 BugCheck** — `MECH-01` 升 `SUPPORTED`（仍非 `PROVEN`） | **不得**推出该次 BugCheck 即为 CSV 停止之因——须另证时序与因果 |
| Minidump 存在，但时间在窗外 | 🟠 本机确有宕机史 → `MECH-01` 之**背景成立** | 不得用于本案时点 |
| Minidump 目录空 | ⚪ 无转储痕迹 | **不得**推出「未曾宕机」——转储可被关闭、清理或覆盖 |
| WER 报告命中浏览器 / Superset 相关进程 | 🟠 该进程曾崩溃 → D/E 枝线索 | 不得推出与本次导出相关 |

## 五、Step 5 · 哈希与清单落档

```powershell
Get-ChildItem $OUT -Recurse -File |
  Get-FileHash -Algorithm SHA256 |
  Select-Object @{n='File';e={$_.Path}},
                @{n='SHA256';e={$_.Hash}},
                @{n='Bytes';e={(Get-Item $_.Path).Length}},
                @{n='CollectedAt';e={(Get-Date).ToString('o')}} |
  Export-Csv (Join-Path $OUT '_MANIFEST.csv') -NoTypeInformation -Encoding UTF8
```

> **⚠️ 编码陷阱**：Windows PowerShell 5.1 之 `-Encoding UTF8` **会写 BOM**，与本项目「UTF-8 无 BOM」之六元组纪律相悖。
> 请择一：以 PowerShell 7 之 `-Encoding utf8NoBOM`，或在清单中标明该档带 BOM。**不得默认无 BOM。**

### 🔒 证物身份锁（须逐字写入清单首行）

```
本目录内全部 .evtx 系 wevtutil epl 之导出产物，非实时日志之字节副本。
```
