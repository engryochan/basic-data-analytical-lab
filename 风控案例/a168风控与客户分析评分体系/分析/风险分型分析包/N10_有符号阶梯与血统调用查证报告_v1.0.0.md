## 二、再答第一问：先生「两侧各别分位」之策

### 2.1 此策直中要害

`N-9 §五之三` 实测四条判据于 P90 处**退化**：`退水支出`(T-08) 尾部占 **100.00 %**、
`rebate_dep`(T-05) 占 **99.96 %**、`opposite_rate`(T-04) 占 **56.64 %**、
`hedge_coverage`(T-04) 占 **44.24 %**。

病根即**零点巨量并列**：全域单一分位遇「九成为零」之分布，P90 即落在 0，
`x ≥ 0` 遂网住全表，判别力归零。**于零点两侧各别起阶梯，正是此病之对症药。**
故先生之策不惟可行，且是本配套现存最大方法缺陷之正解。

### 2.2 然须守三戒，否则仍是作秀

- ⛔ **戒一 · 零点非普适**。`AUC` 之虚无点为 **0.5** 非 0；`economic_value` 系
  `PERCENT_RANK` 之秩（值域 `[0,1]` **恒非负**），零点切分**毫无意义**；`Wilson` 系比例
  区间之端点，非有符号量；主成分之符号由算法**任意定向**。**四者明令拒算**。
  零点须**逐指标声明**（引擎 `.TR_NULLPOINT`），未声明者一律拒算，**不得默认 0**。
- ⛔ **戒二 · 零质量须单列**。若六成行恰为零，两侧阶梯实只建于四成数据之上，不明书即误导。
- ⛔ **戒三 · 承 P-15**。本阶梯系**全窗百分位**，只作描述与诊断，**不得径充赏罚线**。
  欲转处置，仍须过样本外验证与 P-20 之解封。

### 2.3 ⚠ 符号方向之陷阱（本轮实测揭出，足以致命）

`S01_player_score` 实测：

| 栏 | 视角 | 负侧行数 | 正侧行数 | 负侧 profit 占比 |
|---|---|---|---|---|
| `profit` | **平台**（正为庄赢） | 215,481 | 497,232 | **−57.66 %** |
| `roi` | **玩家**（正为玩家赢） | 497,232 | 215,481 | **＋157.66 %** |

**二者符号恰好相反**，行数交叉相等。若以「负数即坏」一体适用于两栏，
**结论将完全颠倒**：把最赚钱的 49.7 万会员当成亏损户来罚。
⇒ 故引擎逐栏声明零点**与读法**，不作跨栏统一假设。此陷阱须先生特别留意。

## 四、能否「补齐全数 133 张表」：实测之答

**不能，且强行为之即是作秀。** 全盘扫描 130 件交付件（总包 133 模块，P4D 落盘 130）：

| 项 | 实测 |
|---|---|
| 指标栏实例总数 | **2,531** |
| **可建阶梯**（原生逐行 ＋ 零点已声明） | **1,039 实例 ／ 59 表** |
| 不可建（广播／全 NA／拒算） | 1,492 实例 ／ 126 表 |

按族：

| 族 | 栏实例 | 可建 | 何以不可建 |
|---|---|---|---|
| NetMargin | 1,008 | 432 | 逾半为六层块广播 |
| 残差 | 758 | 326 | 同上 |
| 盈亏 | 382 | 166 | 同上 |
| ROI | 129 | 59 | 同上 |
| hold | 127 | 55 | 同上 |
| **EconValue** | **126** | **0** | ⛔ 系秩非货币，**明令拒算** |
| Theo／ADT／NMPT／ESI | **0** | 0 | ⛔ 全仓无此栏；`house_edge` 全 NULL（F-22~25 阻断） |
| Drawdown／Sharpe／AUC／Wilson／Spearman／主成分 | 0 | 0 | 非逐行栏，系样本级估计量，不可作列分位 |

### 4.1 三条硬结论

1. **瓶颈不在「补齐指标」，在「修广播」。** 逾半数表之 `roi` / `net_margin` /
   `profit` / `hold_rate` **栏已存在**，然系六层块 `CROSS JOIN` 之平台常数逐行复制。
   于其上建阶梯，十二级门槛将**全数相同**——此即纯粹作秀。
   ⇒ **良策**：欲扩至更多表，须令各表于**自身粒度**重算经济栏，而非广播；
   或将不可信之广播栏**从该表移除**，勿以误导性常数示人。
2. **Theo 族四指标无法以任何分位手法补齐**，病根在 `house_edge` 全 NULL。
   须补 `member × bet09 × 免佣` 之中间粒度，此为 SQL 侧工程，非 R 侧可为。
3. **AUC／Wilson／Spearman／主成分／符号检验系样本级估计量，非逐行列**，
   不可「加为一栏再分位」。其正确用法是**于负侧与正侧两个子群中各别估计**，
   此已列入下轮。

## 五、关于「赏罚分明」与「薄利多销」之管见

先生所言赏罚分明与薄利多销，皆为正途。本轮实测可支撑其**一半**：

- **赏赐面已有明确对象**：正侧 P99 之 4,973 人贡献 94.86 % 净 NGR，
  此为全盘最值得投入留存资源者，且证据坚实。
- **惩罚面亦有明确对象**：负侧 P10 之 21,549 人吃掉 48.79 % 净 NGR。
  ⛔ **然不得据此即罚**——承 **P-16**（禁以实现输赢符号定罚）：
  会员赢钱本身不是过错，须另有**行为判据**（同桌聚集、对冲、套利等）方可处置。
  本阶梯只指出**钱在哪里**，不指出**谁有过错**。二者不可混同。
- **薄利多销尚不可证**。索提诺正侧 3.67 万人系典型薄利多销之形：20.21 % 洗码、
  2.02 % NGR。其 NGR 为**正**（455 万），故非亏损。然「薄利是否划算」取决于
  **单位服务成本 C**，而 **F-26 之 C 至今未知**。
  ⇒ **在 C 未定之前，任何「保留薄利客群划算」或「淘汰之划算」之结论皆无据。**
  求 C 应列为最高优先，其价值高于再加十个指标。
