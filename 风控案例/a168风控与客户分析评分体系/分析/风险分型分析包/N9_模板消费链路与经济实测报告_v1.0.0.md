## 二、每类如何取 133 件中之主表与辅助表

`tr_recipe(REG, tid)`（引擎 §2）：

```r
files <- unique(c(d$primary_deliverable[1L], sup, d$criterion_source))
files <- files[grepl("\.csv$", files)]
```

即**三源取并集**：主交付件 ∪ 搭配交付件（`；`分隔）∪ 该类每条判据之声明源表。
`tr_load_all()` 逐件**全列全行**读入（禁抽样，`tr_fullscan_audit()` 另立闸坐实），
并标角色为 `主表` / `搭配表` / `判据来源`。实测载入件数：T-07 四件、T-09 三件。

**投影**：`tr_load()` 读**全部列**不预筛，投影在后——`tr_criterion_stats()` 按 `criterion_column`
逐判据取数，回 `在位` / `缺列` / `待表` 三态（**永不静默**）；`tr_member_join()` 以 `member_id`
拼跨表面板，并守 **KILL RULE**：登记之判据列若不在其声明源表，**留痕并 BLOCKED**，
不得以 `intersect()` 静默丢弃。

## 四、经济量：1.5.0 之前**只算判据、从不算钱**（本轮补正）

### 4.1 实测揭缺

机检引擎可执行码，`net_margin` / `economic_value` / `theo` / `adt` / `nmpt` / `esi` /
`drawdown` / `sharpe` / `sortino` 命中**皆为 0**。既有者仅 `AUC`(6)、`Wilson`(9)、
`Spearman`(1)、`prcomp`(1)；「符号检验」四字**只见于章名，无实作**。
⇒ 直违军令状。

### 4.2 处置铁律：先验广播，后出金额

十五类主表各含十个经济栏，然多为六层商业块之 **`CROSS JOIN` 平台常数广播**（逐行同值）。
以广播值充金额即是作秀。故 `tr_economic_profile()` 逐栏验相异值数：
逐行同值者**一律拒出**并标「⛔ 禁充金额」；只有本表**原生**栏方可入账。

T-07 主表 `S01_player_score.csv` 实测七栏皆原生：

| 栏 | 合计 | 相异值数 |
|---|---|---|
| stake | 13,436,090,000 | 257,802 |
| valid_bet | 12,101,550,000 | 253,111 |
| profit（NGR） | 225,932,200 | 295,336 |
| rebate_cost | 8,220,756 | 12,588 |

平台 hold ＝ 225,932,200 ÷ 12,101,550,000 ＝ **1.867 %**。

## 五、判据尾部经济暴露：本套配套首次出真金额

`tr_criterion_exposure()`（引擎 §10.4）逐判据算：尾部人群占多少洗码、贡献多少 NGR、
`hold 倍数 ＝ 尾部 hold ÷ 全表 hold`。全十五类实测 **40 条**，落盘
`审计/判据尾部经济暴露_v1.0.0_20260903.csv`。

### 5.1 两处自误当正

1. **尾部方向**：初版一律取上十分位。登记册 `direction = low` 者风险在**下尾**。
   T-07「投注产品结构熵」即遭此误——正后由 `≥P90` 改 `≤P10`，hold 倍数由无义变 **3.744**。
2. **金额取表**：初版一律取主表。全册 65 条判据中 **23 条** `criterion_source ≠
   primary_deliverable`，若不改，此 23 条永不出数。改按**各判据自身声明源表**取金额。

### 5.2 极值（完整 40 条见落盘 CSV）

| 类 | 判据 | 方向 | 尾部 | 行数 | 洗码占比 | NGR 占比 | hold 倍数 |
|---|---|---|---|---|---|---|---|
| T-07 | 投注产品结构熵 | low | ≤P10 | 236,119 | 1.22 % | 4.58 % | **3.744** |
| T-03 | shoe_pos_p50 | — | ≥P90 | 10,056 | 1.67 % | 2.41 % | 1.445 |
| T-05 | hedge_rate | high | ≥P90 | 8,064 | 9.27 % | 12.38 % | 1.335 |
| … | | | | | | | |
| T-04 | opposite_rate | high | ≥P90 | 1,096 | 1.73 % | 0.85 % | 0.489 |
| **T-07** | **索提诺稳定性** | **high** | **≥P90** | **56,710** | **34.26 %** | **8.64 %** | **0.252** |

### 5.3 读法（⛔ 只作暴露描述，不作赏罚）

- **索提诺稳定性上十分位**：56,710 名会员，占会员数 7.84 %，压着 **34.26 % 之洗码**，
  却只出 **8.64 % 之 NGR**——其 hold 率 0.471 %，仅为平台 1.867 % 之**四分之一**。
  此即本套配套迄今指出之**最大单一经济拖累**。
- **投注产品结构熵下十分位**：236,119 名会员，只占 1.22 % 洗码，却出 4.58 % NGR，
  hold 率 6.989 %，为平台之 **3.744 倍**。押注集中者，单位洗码远较分散者出钱。
- **退化判据须另立门槛**：`rebate_dep`(T-05) 尾部占 99.96 %、`退水支出`(T-08) 占 100.00 %、
  `opposite_rate`(T-04) 占 56.64 %——皆因 P90 处大量并列，**判别力近零**，不得据以处置。

⛔ 承 **P-15**（禁以全窗百分位定赏罚线）与 **P-16**（禁以实现输赢符号定罚）：
上列一律为**暴露描述**，非处置依据。欲转为处置，须先解 **P-20**（处置台账／因果封印）。
