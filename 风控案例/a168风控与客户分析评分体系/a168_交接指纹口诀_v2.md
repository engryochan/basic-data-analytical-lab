## 二、口诀六句（v1 四句 ＋ v2 两句）

> **一曰口径宗精简，二曰罚侧一个都不许少；**
> **三曰算得再净仍是推演，四曰无簿子则无因果；**
> **五曰验证器先验其自身，六曰形合非机制、数同非同源。**

**释**：

1. **口径宗精简** —— 能力值以《精要商业报告》为权威，主方案 §18 降为参照。
2. **罚侧不许少** —— 四实体三十一维，赏 17 罚 14。渲染少于 31 维，先查是不是又只少了罚侧。
3. **算得再净仍是推演** —— 回测结论为**决策模拟**，非已实现现金。禁写「本方案将提升盈利 X%」。
4. **无簿子则无因果** —— 处置账未建，CPOS 第七至十二层全空，木桶最弱一环为 0。
5. **验证器先验其自身** —— 自纠册二十一条中，`SC-002/007/016/017/018/020` 六条皆为**我的检验工具失效**，非被检对象出错。**凡验证器须自带可证伪点**（如「未匹配之非注释行 = 0」「前 43,388 行须全命中」）。
6. **形合非机制，数同非同源** —— 形状吻合不是机制证明（`SC-013/014`）；基数相等不是集合相等；三键相同不是记录相同；硬写常量不是执行时点（`SC-015`）。

## 三、体例（新开对话须沿用，不得另立）

- **三十三问法**：十一目 × 三层（**体·用·元**）。第三层是对红队本身的红队。
- **终判五问**：是否入生产／是否可作处罚依据／是否需 A/B／能否证明增量 NGR／红队裁决。
- **每卷定式** = 11×3 + 5 = **38 格**；六十项母标准为其肉（`@sec-t60`）。
- **三轴**：T（标准层 T1–T4）× L（验证层 L1–L9）× S（闸门 S1–S4）。
- **证据等级**：E0–E7。**本方案现最高 E3。**
- **可信度判据**：木桶取 `min`，**不取加权平均**。
- **四层契约**（v2 新立）：**A 表单 / B 数据库 NOT NULL / C 事件成立 / D 因果可用**。四者**允许互不相等**，不得互相偷换。
- **Evidence Grade 与 Gate 分离**（v2 新立）：E0–E7 答「证据多强」；WINDOW/DENSITY/PROVENANCE/SCHEMA Gate 答「够不够资格进下一层」。`E5 + Density FAIL` 可并存，**不得以前者绕过后者**。
- **星级评定**（v2 改判）：**不得自述**，须由「已闭环闸 ÷ 已登记闸」派生，可机械重算。

## 五、五条红线（越之即废）

1. **`0.112` 与 `Spearman 0.20` 不得并列出现**（含转述引用）。
2. **策略层不得使用 `MASE` 一名**。
3. **外部提供之实测数字，须先在源档全文检索定位**；零命中者标「来源不可考」并弃用。
4. **公开披露 ≠ 可归因**。「某公司用后利润提高 X%」须六证齐备，否则只写「公开资料不可归因」。
5. **（v2 新立）不得把「待外部输入」包装成「待分析」。** 代码答不了业务事实；`UNRECOVERABLE` 本身是合法审计结论，**不为求有答案而制造答案**。
