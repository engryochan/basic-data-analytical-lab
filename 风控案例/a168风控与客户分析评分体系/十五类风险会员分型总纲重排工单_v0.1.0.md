## 五、判据灵活组合与单调增强原则（总纲正式条文）

> 十五类风险会员均以统一登记册及 L0–L4 数据底座为共同血统；每一风险类型不绑定固定数量之数据表。现有及未来数据资产均可依风险假说、观察粒度、时间窗口、证据目的及信息增量，跨表灵活组合为核心判据、支持判据、交叉验证判据及探索性判据。
>
> 新增数据表、字段或指标**只允许强化、细化、交叉验证或扩展既有判别能力，不得无说明削弱、删除或替换既有有效证据链**。任何废止、替换或口径改变，必须保留原指标血统、变更原因、影响范围及替代关系，并经 REDTEAM 裁定。
>
> **「增加指标」不等于「增加证据」。** 新指标须经来源、粒度、时间因果、分母、重复计数、NULL 语义、信息增量及与既有指标关系之核验；高度重复、派生无新增信息、存在泄漏者，不得因数量增加而认定为强化。
>
> **允许进化，不允许无审计退化。**

### 5.1 判据四级

| 级 | 名称 | 判准 |
|---|---|---|
| A | 核心判据 | 没有它，风险定义不完整 |
| B | 支持判据 | 不能单独证明风险，但增强核心判据解释力 |
| C | 交叉验证判据 | 来自另一条**独立数据血统**，确认同一风险结构 |
| D | 探索性指标 | 值得研究，尚未准入；EXPLORATORY ≠ PRODUCTION |

### 5.2 新表入池防火墙（新增表 ≠ 自动成为指标）

```text
新数据表 → 字段语义核验 → 粒度核验 → 时间因果核验 → 来源血统核验
        → 与既有指标关系 → 独立信息增量？ → 可进入哪些 T-ID？
```

### 5.3 information_role 标注（防"伪增强"，如同一指标换五个窗口重复计算）

NEW_SIGNAL ／ NEW_WINDOW ／ NEW_GRANULARITY ／ CROSS_VALIDATION ／ DERIVED ／ REDUNDANT ／ EXPLORATORY ／ REPLACEMENT

### 5.4 指标血统不可逆

候选层：M_T^(v) ⊆ M_T^(v+1)。生产判据层：D_T^(v) ≼ D_T^(v+1)（新版本至少保留旧版本之定义能力、证据能力与审计可追溯能力）。任何收缩必须显式登记 **BREAKING CHANGE／退化变更** 并经 REDTEAM 裁定。
唯一法定出口：旧指标查实为错误（分母错、时间穿越、粒度错、NULL 误转 0 等）者可依法废止，但须保留血统、废止原因、影响范围及替代指标。
