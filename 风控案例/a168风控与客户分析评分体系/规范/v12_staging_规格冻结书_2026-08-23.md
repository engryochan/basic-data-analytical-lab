## 二、G-1 ~ G-6 施工规格（设计已锁，代码未动）

### G-1 · `avg_maxround_inflation` 正名 ＋ 数学定义

- 列名：`avg_maxround_inflation` → **`avg_maxround_delta_old_minus_new`**
- 定义（须随列写入注释）：

$$\Delta_{\text{old-new}} \;=\; \overline{maxround_{\text{old}}} \;-\; \overline{maxround_{\text{new}}}$$

- **语义锁**：`Δ > 0` 只表示「旧粒度之平均最大局号高于新粒度」，**不表示旧粒度正确或新粒度错误**。事实与解释分离。
- 同批处理：`n_shoes_delta` 之注释一并去方向预设。

### G-2 · 判词四态 → 五态

```
① ○ n 不足（须 > 3）
② CI 跨 0：方向不可读
③ CI > 0 且 |r| < 0.2：方向显著但实质可忽略（R² < 4%）      ← 新增
④ CI > 0 且 |r| ≥ 0.2：低估假说得证
⑤ CI < 0：与低估假说反向
```

本轮实测：29/30 桌落 ③（r 中位 0.101、R² ≈ 1.02%），1 桌（900，n=72）落 ②。原四态把 ③ 误并入 ④，属过度判读。**「统计显著 ≠ 实质重要」须保留为读表铁律。**
