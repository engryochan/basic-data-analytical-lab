## 二、★ 六项前置阻断（**本契约之核心 · 未解者不得施工**）

裁示定 v12 之验收为四件事：**Registry 执行化 ＋ Grain 锁定 ＋ 十五类商业化 ＋ 风险会员可解释化**。
逐项回溯其前置，**六项现被阻断**：

### B-1 · Registry SSOT 未以代码强制（阻断「Registry 执行化」）

`Z2-03b` 已立：**未以 loader 侧断言强制前，据 CSV 准入列所作之判定一律判 S2 BLOCK。**
而 v12 之核心正是「registry 判据进入 SQL」——**若 SQL 读的是 CSV 投影而非 YAML 真相源，整条链自始即 S2。**

**解除条件**：`registry_loader.R` 侧加 projection-consistency 断言（YAML→CSV 单向派生之机器证明），
并出 round-trip / hash 一致性报告。

### B-2 · `registry_loader.R` 血统失锚未销（S2）

```
在册登记   447 行 ／ MD5 c90f7547…
现档实测   499 行 ／ MD5 c99c01071c3b344bc72b1ca56b6c2f34
```

**差 52 行。** 契约探针 v1.0.4 虽判「子集读取 CONFIRMED」，惟**所验者系现档，非在册档**。
→ 须补 SC，重锚六元组；否则 v12 之 registry 绑定建在一个身份不明的 loader 上。

### B-3 · 十五类之 grain 尚未逐类定谳（阻断「Grain Lock」）

裁示要求每指标锁定 `PLAYER ／ PLAYER×DAY ／ PLAYER×DEALER ／ PLAYER×TABLE ／ PLAYER×GAME ／ PLAYER×RISK_TYPE`。
**而十五类之 grain 正是 A–F 只读审查（批-03 ~ 批-09）之产出物**，现只走到批-01。

> **先定 grain 再写指标，是 `R4-SEMANTIC-01` 在指标层之延伸。**
> 未审即写，必重蹈「先算 ROI 再找它是什么意思」之覆辙（`G-METRIC-01` 明禁）。

**解除条件**：批-02 至批-11 审毕，十五类 grain 逐类登记。

### B-4 · ROI 之零假设 μ0(g,w) 现为 UNKNOWN（阻断「ROI 按 grain 锁定」）

`Z2-01` 已立：分层 μ0 各组值须由域级总帐**按组反号现算**后方得登记，**现未现算**。
→ ROI 若入 SQL 而无分层基准，则「跑赢 0」与「跑赢赌场」之别在执行层即失守。

**解除条件**：按 `bet09` 注型组 × 窗口现算 hold%(g,w)，登记各组 μ0。

### B-5 · `bet16`／`validbet` 未在名单交付（阻断「十五类商业化」）

`R01_late_shoe.csv` 十五列**只到毛利 GGR，到不了 NGR**。
退水（`bet16`）与洗码量（`validbet`）未交付 → **E4（成本）与 E5（净额）几近全数 `BLOCKED_UPSTREAM`**。
而 T-01／T-04／T-05／T-08 之经济机制**恰在扣项里**——毛利层指标对这四类近乎无效。

> **此为「商业化」之唯一钥匙。** 无 NGR 而言商业名单，只能停在「参考统计」。

**解除条件**：名单增列规格立案，`bet16`／`validbet` 入交付件。

### B-6 · T-03 系 REFUTED，其入 SQL 之身份须先定

`Z2-08` 机械禁令已立：REFUTED 者不得恢复 `admit_to_risk_decision`。
则 v12「registry 判据真正进入 SQL」对 T-03 意味什么？**须先明书**：

```
REFUTED 类之判据可入 SQL，惟只得进 PROFILE_ONLY 层，
产出「档案列」而非「触发列」；且其输出须携 REFUTED 标记，
下游不得据以行处置。违者判 S1。
```

**解除条件**：本条写入 v12 之输出契约。

## 三、C2 变更项目录（四引擎 · 待逐项裁定）

**每项须填十问**（承裁示第三节），缺一不得施工：
分子／分母／grain／窗口／NULL 处置／零分母处置／可否重复计数／可否跨 dealer-table-game 合并／绑 registry 何条目／商业解释。

### 引擎一 · Registry Engine

| 项 | 内容 | 依赖 |
|:--|:--|:--|
| RE-1 | YAML 为 SQL 判据之唯一上游；SQL 内不得硬编阈值 | B-1, B-2 |
| RE-2 | 十五类 × 六十六判据之 SQL 表达映射表 | B-3 |
| RE-3 | **商业阈值越权闸**：商业方案不得以「我觉得 ROI > 10%」代 registry 判据 | RE-1 |

### 引擎二 · Metrics Engine

| 项 | 内容 | 依赖 |
|:--|:--|:--|
| ME-1 | 十五类各自之 `ROI ／ AVG ／ RATE`——**名可统一，式按 grain 锁定** | B-3, B-4 |
| ME-2 | `allowed ／ required ／ forbidden_metrics` 逐类登记 | `G-METRIC-02` |
| ME-3 | `EXPLORE ／ RAMP` 仍只登记为 **metric family**，禁擅冻数学式 | `G-METRIC-03` |
| ME-4 | E4／E5（成本／净额）层 —— **BLOCKED，俟 B-5** | B-5 |

### 引擎三 · Commercial Engine

| 项 | 内容 | 依赖 |
|:--|:--|:--|
| CE-1 | Risk Member Fact 表：`member × risk_typology × registry_id × evidence_level × trigger 时点 × severity` | RE-2, ME-1 |
| CE-2 | Commercial Eligibility 层 —— **只得由 H 轴计算，禁引 V 轴**（六不污染第六条） | H_PARTIAL |
| CE-3 | 输出须能答「**为何此会员进入风险名单**」，非「此会员数字异常」 | CE-1 |

### 引擎四 · Output Engine

| 项 | 内容 | 依赖 |
|:--|:--|:--|
| OE-1 | 输出字段 lineage：每列可回溯至原始事实 | 全部 |

| OE-3 | REFUTED 类之 PROFILE_ONLY 输出规格 ＋ 标记列 | B-6 |

## 四、新增 G 闸规格（C2 层 · 待裁）

G1–G11 验 **syntactic ／ structural** 正确；C2 须再验 **semantic ／ commercial** 正确。

| 闸 | 名 | 判据 |
|:--|:--|:--|
| **G12** | Registry ↔ SQL 对齐 | SQL 内每一判据皆可回溯至 YAML 条目；**SQL 内零硬编阈值** |
| **G13** | Typology 穷尽性 | 十五类 ＋ 一价值轴皆有表达；无孤儿、无重叠未声明 |
| **G14** | Grain Lock | 每指标携 `metric_grain`；**聚合前之原始 grain 须明书** |
| **G15** | 分母完整性 | ROI／AVG／RATE 各自之分母皆登记；零分母处置皆 `NULLIF` 或明书 |
| **G16** | NULL ／ 重复计数 | NULL 语义明书；去重键明书（承 `rn=1` 纪律） |
| **G17** | 时间窗口一致性 | 全包窗口字面量单一来源；跨窗指标须明书其窗 |
| **G18** | **商业阈值越权** | 凡阈值皆须有 registry 条目或 Contract 授权；裸阈值即 FAIL |
| **G19** | 输出 lineage | 每输出列可回溯；下游 `must=` 同步无缺 |
| **G20** | **REFUTED 隔离** | REFUTED 类之输出不得出现于触发列或处置列 |

**原则**：**「有 SQL 输出」≠「指标实现正确」。**

## 六、三条铁律（承裁示，原样照录并加一条）

**其一** `v11.0.3` **永久只读**：不得改 SQL、不得回写、不得以 v12 结果覆盖、
不得因 v12 施工而重新解释其既有验收结果。**它是基准尺。**

**其二** v12 系真正之 C2：`WHERE`／`JOIN`／`GROUP BY`／CTE／窗口函数／指标公式／
grain／registry 判据／输出字段／风险分类逻辑 —— 皆属实质变更，**不得伪装为 PATCH**。

**其三** v12 之「强」不以代码行数衡量，以四件事衡量：
**Registry 执行化 ＋ Grain 锁定 ＋ 十五类商业化 ＋ 风险会员可解释化。**

**其四（本契约新加）** **阻断不得以「先做着看」绕过。**
B-1 ~ B-6 各有明确解除条件；未解而施工者，其产出**一律判 UNVERIFIED**，
不得进入交付件，亦不得作商业方案之依据。
理由：B-4 未解则 ROI 无基准、B-5 未解则 NGR 算不出——**此二者一缺，
「商业化」即名不副实**，届时 v12 仍只能停在「这些数字可以参考」。
