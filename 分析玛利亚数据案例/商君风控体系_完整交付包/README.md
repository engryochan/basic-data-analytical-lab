# 商君风控体系 · 完整交付包说明

本包对应报告 `01_报告/商君风控体系之数据篇.qmd`——从129张原始ODS表出发，
到最终产出24人最高置信度复核名单的完整链路，全部环节均在真实数据
（StarRocks在线库，`ods_mariadb_2b.ods_a168_bet01`全表173,529,760行，
2026-03-21至2026-07-24共126天无缺口）上验证过，无一处凭空编造。

## 文件夹结构

### 01_报告/
- `商君风控体系之数据篇.qmd` —— 主报告，Quarto格式，含第一部(工具/标准/数据)、
  第二部(样本规模说明/129表分类)、第三部(第七章统计建模+第八章执行摘要)
- `春秋战国主题.css` —— 报告视觉主题，纯样式文件，不影响任何计算逻辑

**渲染方法**：把这两个文件放在同一目录，配合`02_真实数据/`里的CSV，
用Positron/RStudio执行 `quarto render 商君风控体系之数据篇.qmd`

### 02_真实数据/ —— 全部是从StarRocks在线库实测下载的真实数据，非样本、非模拟
- `候选_同桌异常_最终版_已去重.csv` —— 59,833组团伙同桌候选配对，
  按月分5批下载后本地合并去重，覆盖全量126天数据，零采样误差
- `策略性投注_候选明细.csv` —— 4,929人策略性投注候选明细
- `双重命中_策略性投注与团伙同桌.csv` —— 24人，同时命中两个独立风控
  标准的最高置信度名单，是本项目目前最重要的单一产出

### 03_核心代码/ —— 当前仍在使用、已验证可运行的代码
- `customer_tier_engine_v2.R` —— 客户分级引擎（真实a168 schema版）
- `同桌特征_按月分批版.sql` —— 团伙同桌数据下载SQL（已修复自连接方向bug，
  `a.bet05 < b.bet05`，避免镜像重复配对）
- `需求一_策略性投注_明细下载.sql` —— 策略性投注数据下载SQL
- `合并五批同桌配对数据.R` —— 本地合并5批CSV+跨批次加总+最终阈值筛选
- `诊断_commission与category字段.sql` / `诊断_bet41真实含义.sql` ——
  盈亏字段排查过程SQL（结论：现有129张表无法支撑盈亏分析，详见报告2.8节）
- `本地数据归档.ps1` —— 本地文件夹归档脚本

### 04_历史归档/ —— 项目演进过程的完整记录，不建议再直接使用，但保留供追溯
- `当前有效/` —— 上一版本的"当前有效"快照(现已被01/03文件夹取代)
- `历史归档_10万行样本时代/` —— 项目早期基于本地10万行抽样样本的分析产物
  (129表分类目录、joinability_scan等)，已被StarRocks全量数据分析取代
- `历史归档_SQL迭代过程/` —— 从最初的CREATE TABLE版本，到DDL权限受限、
  类型转换报错、schema歧义、内存超限等一路调试修复的完整SQL版本历史，
  每一版都对应一次真实踩过的坑，供以后遇到类似报错时查阅参照
- `通用工具_非本项目专属/` —— fix_ranef_type_mismatch.R、
  loo_diagnostics_pipeline.R等跟本风控项目无关但可能还用得上的独立工具

### 05_源数据_129张原始表/数据库/ —— 第三章"数据审核"实际读取的源数据
- 129张`ods_a168_*.csv`原始表，本地10万行样本版本(与2026-07-23上传的
  `分析玛利亚数据案例.zip`一致)
- **报告第三章("数据盘点/正名/审核")的代码就是读取这个文件夹**——渲染
  报告前，请把这个文件夹路径对应到qmd里`路径 <- file.path(getwd(), "数据库")`
  这一行，或者直接把这个文件夹重命名为`数据库`放在跟qmd同级目录下
- **注意**：这批是本地10万行样本，不是StarRocks在线1.74亿行全量库——
  报告第二部第五章已经把这两者的差异讲得很清楚，第三章基于这批样本做的
  审核结论（字段类型/缺失率等）仍然成立，但涉及"全量规模验证"
  （如132,982人候选、59,833组配对）的部分，是另外通过StarRocks在线
  查询得到的，结果已经存在`02_真实数据/`文件夹里，不需要重新连库计算


## 项目全链路概览（供快速回顾）

```
129张ods_a168_xxx原始表(StarRocks在线库)
  ↓ 分类审核(12大业务类别) + 跨表连接性扫描
9张确认可用于建模的核心表
  ↓ 全量聚合(投注异常118,946 + 同桌异常62,245 + 荷官关联70,217)
132,982人候选名单(零采样误差)
  ↓ 团伙同桌：按月分5批下载(内存/超时限制所致) + 本地合并去重
59,833组同桌配对候选
  ↓ 图论建模(Louvain社区发现) + 贝叶斯层级模型 + XGBoost + Stacking融合
53个真实团伙候选社区 / AUC 0.920(XGBoost最优)
  ↓ 策略性投注候选(4,929人) 与 团伙同桌候选 跨维度交叉验证
24人最高置信度双重命中名单 ← 本项目当前最重要的单一产出
```
