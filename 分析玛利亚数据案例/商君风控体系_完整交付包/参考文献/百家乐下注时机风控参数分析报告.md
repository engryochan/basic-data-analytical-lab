# 下注时机风控参数分析报告

## 一、分析目的

本次分析用于确定“策略性后段下注”风控规则的合理参数，重点验证：

1. 从第几局开始定义为后段下注；
2. 后段下注订单占比达到多少视为异常；
3. 玩家至少累计多少订单后才纳入判断。

最终建议规则：

> **统计第40局及以后下注的订单；第40局及以后订单占玩家总订单比例达到60%及以上；玩家总订单数达到30笔及以上。**

建议输出：

- `player_id`：会员ID；
- `total_orders`：总订单数；
- `late_orders`：第40局及以后订单数；
- `late_ratio`：第40局及以后订单占比；
- `valid_bet`：有效投注；
- `profit`：玩家盈利；
- `roi`：玩家投资回报率；
- `win_rate`：胜单率。

## 二、数据口径

### 2.1 关键字段

| 字段 | 业务含义 |
|---|---|
| `bet02` | 游戏类别，`101`代表本次分析的百家乐游戏 |
| `bet03` | 场次编号，可视为一靴牌 |
| `bet04` | 子场次编号，即当前牌靴的局号 |
| `bet05` | 会员ID |
| `bet11` | 汇率 |
| `bet13` | 下注金额 |
| `bet14` | 派彩金额 |
| `validbet` | 有效投注 |

### 2.2 核心指标

```text
total_orders = 玩家在分析期间的百家乐总订单数

late_orders = 玩家在第40局及以后产生的订单数

late_ratio = late_orders / total_orders

profit = Σ[(派彩金额 - 下注金额) / 汇率]

valid_bet = Σ[有效投注 / 汇率]

ROI = profit / valid_bet
```

“订单数达到30笔”指玩家的百家乐总订单数达到30笔，并非要求第40局及以后订单数达到30笔。

如果业务要求靴尾订单本身也不少于30笔，应额外增加：

```sql
late_orders >= 30
```

## 三、牌靴长度验证

以 `bet03` 作为牌靴编号，统计每靴最大局号：

| 统计指标 | 每靴局数 |
|---|---:|
| 平均值 | 49.86 |
| P50 | 50 |
| P75 | 52 |
| P90 | 54 |
| P95 | 55 |
| P99 | 58 |

一靴牌通常约为50局，因此：

- 第35局大约处于牌靴后30%的位置；
- 第40局大约处于牌靴最后20%的位置；
- 第45局大约处于牌靴最后10%的位置；
- 第50局已经接近多数牌靴的结束位置。

第35局覆盖范围偏宽；第45局虽然异常性更强，但会造成命中人数明显减少。第40局既属于牌靴明显后段，又能保留足够的风险观察样本，因此更适合作为后段下注起始局号。

## 四、玩家平均首次下注局号分析

### 4.1 计算口径

先计算每位玩家在每一靴的首次下注局号：

```text
first_bet_round = MIN(bet04)
```

再计算玩家跨牌靴的平均首次下注局号：

```text
avg_first_round = AVG(first_bet_round)
```

分析只保留参与至少30靴的玩家，以减少小样本波动。

### 4.2 分位数结果

| 分位数 | 平均首次下注局号 |
|---|---:|
| P50 | 24.95 |
| P75 | 27.46 |
| P90 | 29.85 |
| P95 | 31.47 |
| P99 | 35.03 |

结果表明：

- 50%的活跃玩家平均在第25局以前首次下注；
- 90%的玩家平均在第30局以前首次下注；
- 95%的玩家平均在第31至32局以前首次下注；
- 99%的玩家平均首次下注局号不超过约35局。

因此，平均在第40局及以后才开始下注，已经明显超过P99范围，属于极少数行为。

需要注意，`avg_first_round` 与 `late_ratio` 是两个不同指标：

- `avg_first_round` 描述玩家通常从第几局开始下注；
- `late_ratio` 描述玩家全部订单中有多少发生在第40局及以后。

首次下注局号分布可以支持“第40局属于极端靠后的入场位置”，但最终规则仍需结合第40局以后订单占比判断。

## 五、为什么选择第40局

在“后段订单占比达到60%、总订单数达到30笔”的条件下：

| 起始局号 | 命中人数 | 平均ROI | ROI P90 | ROI P95 | 盈利玩家占比 |
|---:|---:|---:|---:|---:|---:|
| 35 | 11,791 | -4.15% | 20.69% | 30.40% | 36.60% |
| **40** | **2,644** | **-4.61%** | **25.86%** | **38.62%** | **37.93%** |
| 45 | 263 | -7.05% | 31.37% | 45.95% | 36.50% |

选择第40局的依据：

1. 第40局处于典型牌靴最后约20%的区间；
2. 明显晚于玩家平均首次下注位置P99的35.03局；
3. 命中人数从第35局的11,791人降低到2,644人，过滤能力明显增强；
4. ROI P95从30.40%提升到38.62%；
5. 相比第45局，仍能保留更充分的风险观察样本。

第45局虽然具有更高的ROI P95，但只命中263人，容易遗漏在第40至44局集中下注的玩家。第40局在异常程度、风险强度和名单召回率之间更加平衡。

## 六、为什么订单占比选择60%

固定条件为“第40局及以后下注、总订单数达到30笔”：

| 占比阈值 | 命中人数 | 平均ROI | ROI P90 | ROI P95 | 盈利玩家占比 |
|---:|---:|---:|---:|---:|---:|
| ≥40% | 15,353 | -3.75% | 20.49% | 30.11% | 37.56% |
| ≥50% | 6,290 | -4.19% | 23.47% | 33.90% | 37.44% |
| **≥60%** | **2,644** | **-4.61%** | **25.86%** | **38.62%** | **37.93%** |
| ≥70% | 1,132 | -4.97% | 27.39% | 43.67% | 37.10% |

分析结果：

- 40%命中15,353人，名单规模过大；
- 50%仍命中6,290人，区分度有限；
- 60%命中2,644人，ROI P90和P95均明显提高；
- 70%虽然ROI P95进一步提高，但命中人数下降到1,132人，召回损失更大。

因此，60%适合作为重点审核阈值；70%可以作为更高异常等级，但不建议作为主筛选阈值。

## 七、为什么订单数选择30笔

固定规则为“第40局及以后下注占比达到60%”：

| 订单门槛 | 命中人数 | 平均ROI | ROI P90 | ROI P95 | 平均有效投注 | 盈利玩家占比 |
|---:|---:|---:|---:|---:|---:|---:|
| **≥30** | **2,644** | **-4.61%** | **25.86%** | **38.62%** | **8,704.80** | **37.93%** |
| ≥50 | 1,170 | -4.10% | 21.66% | 31.27% | 17,885.71 | 37.86% |
| ≥100 | 393 | -3.31% | 10.88% | 20.46% | 47,136.12 | 37.15% |

30单门槛可以：

- 排除只有少量订单但比例偶然达到100%的玩家；
- 保留2,644人的可观察名单；
- 避免50单和100单门槛造成过度漏报；
- 保留较明显的ROI尾部风险信号。

30单并不代表比例已经达到严格统计稳定，而是异常识别、名单规模和审核能力之间的业务折中。

## 八、最终推荐规则

### 8.1 主规则

```text
游戏类型为百家乐；
第40局及以后订单占比达到60%；
玩家总订单数达到30笔。
```

对应判断条件：

```sql
total_orders >= 30
AND late_orders * 1.0 / total_orders >= 0.60
```

其中：

```sql
late_orders =
SUM(
    CASE
        WHEN CAST(bet04 AS INT) >= 40 THEN 1
        ELSE 0
    END
)
```

### 8.2 风险分层参考

| 层级 | 规则 | 用途 |
|---|---|---|
| 观察 | 第40局以后占比≥40%，总订单≥30 | 玩家画像、行为观察 |
| 关注 | 第40局以后占比≥50%，总订单≥30 | 提高关注等级 |
| **重点审核** | **第40局以后占比≥60%，总订单≥30** | **推荐主规则** |
| 高度异常 | 第40局以后占比≥70%，总订单≥30 | 更高异常等级 |
| 稳定异常 | 第40局以后占比≥60%，总订单≥50 | 二次复核 |

## 九、命中玩家及盈利情况SQL

```sql
WITH player_stat AS (
    SELECT
        CAST(bet05 AS BIGINT) AS player_id,

        COUNT(*) AS total_orders,

        SUM(
            CASE
                WHEN CAST(bet04 AS INT) >= 40 THEN 1
                ELSE 0
            END
        ) AS late_orders,

        SUM(
            CASE
                WHEN CAST(bet14 AS DECIMAL(20,4))
                   > CAST(bet13 AS DECIMAL(20,4))
                THEN 1
                ELSE 0
            END
        ) AS win_orders,

        SUM(
            (
                CAST(bet14 AS DECIMAL(20,4))
                - CAST(bet13 AS DECIMAL(20,4))
            )
            / NULLIF(CAST(bet11 AS DECIMAL(20,4)), 0)
        ) AS profit,

        SUM(
            CAST(validbet AS DECIMAL(20,4))
            / NULLIF(CAST(bet11 AS DECIMAL(20,4)), 0)
        ) AS valid_bet

    FROM ods_a168_bet02

    WHERE bet02 = '101'
      AND bet03 IS NOT NULL
      AND bet04 IS NOT NULL
      AND bet05 IS NOT NULL

    GROUP BY CAST(bet05 AS BIGINT)
)

SELECT
    player_id,
    total_orders,
    late_orders,

    ROUND(
        late_orders * 1.0 / total_orders,
        4
    ) AS late_ratio,

    win_orders,

    ROUND(
        win_orders * 1.0 / total_orders,
        4
    ) AS win_rate,

    ROUND(valid_bet, 2) AS valid_bet,
    ROUND(profit, 2) AS profit,

    ROUND(
        profit / NULLIF(valid_bet, 0),
        4
    ) AS roi

FROM player_stat

WHERE total_orders >= 30
  AND late_orders * 1.0 / total_orders >= 0.60

ORDER BY
    roi DESC,
    profit DESC;
```

胜率暂以 `bet14 > bet13` 判断胜单。如存在和局、退款、取消单、重复订单或特殊佣金结算，应根据 `bet17` 的业务取值重新定义胜率。

## 十、使用边界

该规则识别的是：

> **下注订单高度集中在牌靴后段的异常行为玩家。**

它不能单独证明玩家作弊、串通或利用牌面信息，原因包括：

- 命中玩家的平均ROI仍然为负；
- 异常信号主要体现在ROI的P90和P95尾部；
- 部分玩家可能只是习惯观察牌路或中途进入游戏；
- 小额玩家的ROI容易受到单次输赢影响；
- 当前结论来自有限月份的历史数据，仍需用后续月份进行样本外验证。

因此，本规则适合用于异常行为筛查和人工审核，不建议单独作为自动封禁或处罚依据。

## 十一、最终结论

综合牌靴长度、平均首次下注局号分布和参数扫描结果，建议采用：

> **第40局及以后下注订单占比达到60%，且玩家总订单数达到30笔。**

选择依据：

1. 一靴平均约49.86局，第40局已进入最后约20%的牌局；
2. 玩家平均首次下注局号P99约为35.03，第40局明显晚于绝大多数玩家的平均入场位置；
3. 第40局、60%、30单组合命中2,644人，名单规模比第45局规则更充分；
4. 该组合ROI P90为25.86%、P95为38.62%，高收益尾部特征较明显；
5. 60%比40%和50%具有更强区分度，同时比70%保留更多风险召回；
6. 30单可以排除极小样本，并避免50单和100单门槛造成过度漏报。

最终定位：

> **该规则是策略性靴尾下注的行为筛查规则，适合风险观察和人工审核，不应单独作为作弊认定或自动处罚依据。**
