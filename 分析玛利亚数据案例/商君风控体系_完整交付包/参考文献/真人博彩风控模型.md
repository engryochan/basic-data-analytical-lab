# Risk Score 真人博彩风控模型

## 一、数据来源

- player_pair_stat_hourly
- dealer_profit_stat_hourly

## 二、指标设计思路

### 设计原则
- 能反映异常盈利
- 能反映异常游戏行为
- 能反映玩家之间的关联关系
- 指标可解释、可量化
- 阈值来源于历史数据统计，而非经验值

### 指标分类
（1）盈利指标（Profitability）
包括：ROI、Profit。
ROI反映盈利效率，Profit反映盈利规模，两者结合避免仅凭高ROI或高利润造成误判。

（2）行为指标（Behavior）
包括：Round Count。
局数用于过滤样本不足的玩家，避免因少量游戏导致ROI等指标失真。本项目设置 Round Count≥100、Valid Bet≥660 作为评分门槛。

（3）关系指标（Relationship）
Top1 Dealer Ratio：玩家与游戏局数最多的荷官的局数 ÷ 玩家总局数，用于识别是否长期集中与某一荷官游戏。

Top1 Partner Ratio：玩家与同桌次数最多的玩家的同桌局数 ÷ 玩家总局数，用于识别是否长期与固定玩家共同游戏。

## 四、计算sql

```
1.计算利润和roi
WITH player_stat AS (
    SELECT
        player_id,
        SUM(bet_count) AS bet_count,
        SUM(round_count) AS round_count,
        SUM(valid_bet) AS valid_bet,
        SUM(turnover) AS turnover,
        SUM(profit) AS profit,
        SUM(profit) / NULLIF(SUM(valid_bet),0) AS roi,
        SUM(win_count) / NULLIF(SUM(round_count),0) AS win_rate
    FROM wm_risk.dealer_profit_stat_hourly
    GROUP BY player_id
    HAVING SUM(valid_bet) >= 10000
       AND SUM(round_count) >= 100
),

ordered AS (
    SELECT
        *,
        ROW_NUMBER() OVER (ORDER BY roi)         AS roi_rn,
        ROW_NUMBER() OVER (ORDER BY win_rate)    AS win_rn,
        ROW_NUMBER() OVER (ORDER BY profit)      AS profit_rn,
        ROW_NUMBER() OVER (ORDER BY valid_bet)   AS bet_rn,
        ROW_NUMBER() OVER (ORDER BY round_count) AS round_rn,
        COUNT(*) OVER () AS total
    FROM player_stat
)

SELECT
    MAX(CASE WHEN roi_rn    = CEIL(total * 0.95) THEN roi END)        AS roi_p95,
    MAX(CASE WHEN roi_rn    = CEIL(total * 0.99) THEN roi END)        AS roi_p99,

    MAX(CASE WHEN win_rn    = CEIL(total * 0.95) THEN win_rate END)   AS win_p95,
    MAX(CASE WHEN win_rn    = CEIL(total * 0.99) THEN win_rate END)   AS win_p99,

    MAX(CASE WHEN profit_rn = CEIL(total * 0.95) THEN profit END)     AS profit_p95,
    MAX(CASE WHEN profit_rn = CEIL(total * 0.99) THEN profit END)     AS profit_p99,

    MAX(CASE WHEN bet_rn    = CEIL(total * 0.95) THEN valid_bet END)  AS valid_bet_p95,
    MAX(CASE WHEN bet_rn    = CEIL(total * 0.99) THEN valid_bet END)  AS valid_bet_p99,

    MAX(CASE WHEN round_rn  = CEIL(total * 0.95) THEN round_count END) AS round_p95,
    MAX(CASE WHEN round_rn  = CEIL(total * 0.99) THEN round_count END) AS round_p99
FROM ordered;

2.Dealer Ratio
WITH player_total AS (
    SELECT
        player_id,
        SUM(round_count) AS total_round,
        SUM(valid_bet) AS total_valid_bet
    FROM wm_risk.dealer_profit_stat_hourly
    GROUP BY player_id
    HAVING
        SUM(valid_bet) >= 660
        AND SUM(round_count) >= 66
),

dealer_stat AS (
    SELECT
        player_id,
        dealer_id,
        SUM(round_count) AS dealer_round
    FROM wm_risk.dealer_profit_stat_hourly
    GROUP BY player_id, dealer_id
),

dealer_ratio AS (
    SELECT
        d.player_id,
        MAX(d.dealer_round / p.total_round) AS top1_dealer_ratio
    FROM dealer_stat d
    JOIN player_total p
        ON d.player_id = p.player_id
    GROUP BY d.player_id
),

ordered AS (
    SELECT
        top1_dealer_ratio,
        ROW_NUMBER() OVER (ORDER BY top1_dealer_ratio) AS rn,
        COUNT(*) OVER () AS total
    FROM dealer_ratio
)

SELECT
    MAX(CASE WHEN rn = CEIL(total * 0.95) THEN top1_dealer_ratio END) AS p95,
    MAX(CASE WHEN rn = CEIL(total * 0.99) THEN top1_dealer_ratio END) AS p99
FROM ordered;
3.玩家同桌率
WITH player_total AS (
    
    SELECT
        player_id,
        SUM(round_count) AS total_round,
        SUM(valid_bet) AS total_valid_bet
    FROM wm_risk.dealer_profit_stat_hourly
    GROUP BY player_id
    HAVING
        SUM(valid_bet) >= 660
        AND SUM(round_count) >= 66
),

partner_stat AS (

    
    SELECT
        player_a AS player_id,
        player_b AS partner_id,
        SUM(same_round_count) AS same_round
    FROM wm_risk.player_pair_stat_hourly
    GROUP BY player_a, player_b

    UNION ALL

    
    SELECT
        player_b AS player_id,
        player_a AS partner_id,
        SUM(same_round_count) AS same_round
    FROM wm_risk.player_pair_stat_hourly
    GROUP BY player_b, player_a
),

partner_ratio AS (

    SELECT
        p.player_id,

        MAX(p.same_round) AS top1_same_round,

        MAX(p.same_round * 1.0 / t.total_round) AS top1_partner_ratio

    FROM partner_stat p
    JOIN player_total t
        ON p.player_id = t.player_id
    GROUP BY p.player_id
),

ordered AS (

    SELECT
        top1_partner_ratio,
        ROW_NUMBER() OVER (ORDER BY top1_partner_ratio) AS rn,
        COUNT(*) OVER () AS total
    FROM partner_ratio
)

SELECT

    COUNT(*) AS player_count,

    AVG(top1_partner_ratio) AS avg_ratio,

    MIN(top1_partner_ratio) AS min_ratio,

    MAX(top1_partner_ratio) AS max_ratio,

    MAX(CASE
            WHEN rn = CEIL(total * 0.95)
            THEN top1_partner_ratio
        END) AS p95,

    MAX(CASE
            WHEN rn = CEIL(total * 0.99)
            THEN top1_partner_ratio
        END) AS p99

FROM ordered; 
```

## 五、Risk Score
基础评分：ROI、Profit、Top1 Dealer Ratio、Top1 Partner Ratio 均采用 0/10/20 分；Round Count≥100 后进入评分。

组合加分：
- ROI>P95 且 Profit>P99：+10
- Profit>P95 且 Partner Ratio>P95：+10

风险等级：Low、Medium、High、Critical。

## 六、案例分析

```
SELECT
    player_id,
    SUM(valid_bet) AS valid_bet,
    SUM(profit) AS profit,
    SUM(round_count) AS round_count,
    SUM(profit) / SUM(valid_bet) AS roi
FROM wm_risk.dealer_profit_stat_hourly
GROUP BY player_id
HAVING SUM(valid_bet) >= 660
   AND SUM(round_count) >= 100
ORDER BY profit DESC
LIMIT 20;
```
