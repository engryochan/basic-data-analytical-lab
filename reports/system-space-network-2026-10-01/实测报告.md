日期：2026-10-01，Asia/Tbilisi。只读查询；没有删除文件、修改分区、关闭服务或变更安全策略。

## C 盘空间

Windows 的 GB 显示通常按 1,073,741,824 字节计算；本报告记为 GiB。

首次 Get-PSDrive：已用 192,570,744,832 字节（179.35 GiB），可用 62,132,891,648 字节（57.87 GiB）。后续读数：已用 192,753,053,696 字节（179.52 GiB），可用 61,950,582,784 字节（57.70 GiB）。这是运行中机器不同时间的读数，未冻结文件系统。

管理员 fsutil volume diskfree 的独立读数：

- C 盘总量：254,703,636,480 字节（237.21 GiB）。
- 可用：62,135,259,136 字节（57.87 GiB）。
- NTFS 已用：189,811,560,448 字节（176.78 GiB）。
- 保留：2,756,816,896 字节（2.57 GiB）。
- 上述可用、已用、保留三者恰好相加等于总量。

所以，资源管理器的“已用”并不全是普通文件内容：它还包含不可供用户使用的保留空间。

管理员 fsutil volume allocationreport 完成了全卷分配分类：

| 类别 | 文件/目录计数 | 分配字节 | GiB |
|---|---:|---:|---:|
| NTFS 用户文件类别（也含操作系统普通文件和分页文件） | 996,181 | 183,226,417,152 | 170.6429 |
| 用户目录 | 230,095 | 615,063,552 | 0.5728 |
| NTFS 系统元数据文件 | 29 | 2,701,160,448 | 2.5157 |
| System Volume Information | 文件17，目录14 | 3,264,950,272 | 3.0407 |
| 合计 | — | 189,807,591,424 | 176.7721 |

四类相加恰好等于 allocationreport 报告的全部已分配字节，已用类别未留未归类余额。其头部总量、空闲和分配计数间相差 4,075,520 字节（约3.89 MiB），已保留在核对 JSON 中；这是运行中扫描，不能把不同采样时刻计数当作冻结快照。diskfree 的同次读数则完全平衡。两种查询相差数 MiB，未发现几十 GiB 的无法归类已分配空间。

其他实测：

- pagefile.sys 文件大小：17,081,303,040 字节（15.91 GiB）。
- 卷影副本：已用约2.56 GiB、已分配约2.96 GiB；包含在 System Volume Information 中，不再重复加到总量。
- $Mft 已分配：2,511,908,864 字节（2.34 GiB）；包含在 NTFS 系统元数据中。
- 恢复数据库：1,971 个文件，30,391,105,001 字节（28.30 GiB），已重新实测。此前恢复必然增加本地文件占用，不能把增加的这批文件归因于远端服务器。
- 当前 .git/objects/pack 主 pack：8,186,574,844 字节（7.62 GiB）；是历史对象存储，不是隐藏分区。

额外逐路径元数据扫描未完成全盘：句柄扫描在约100,000文件后停止，快速目录扫描在约200,000文件后停止。它们用于诊断方法对比，不能冒充完整逐路径清单。空间总量结论依据已经完成的 Windows 原生全卷分配报告，而非这两份部分扫描。扫描不读取普通文件内容；未关闭安全软件，也未改变目录 ACL。

## 分区

实测仅有磁盘0：BORY R500 256G，GPT，256,060,514,304 字节。

| 分区 | 类型 | 大小 | 隐藏 | 盘符 |
|---|---|---:|---|---|
| 1 | System / EFI | 300 MiB | 是 | 无 |
| 2 | Microsoft Reserved | 16 MiB | 是 | 无 |
| 3 | Basic / Windows | 237.21 GiB | 否 | C |
| 4 | Recovery | 975 MiB | 是 | 无 |

三个隐藏分区合计1,291 MiB（约1.26 GiB），在 C 分区之外。类型符合微软标准 UEFI/GPT 的系统、保留、Windows、恢复布局。未发现额外的大容量隐藏分区；这不是对固件、未分配扇区或整个设备的安全取证。
