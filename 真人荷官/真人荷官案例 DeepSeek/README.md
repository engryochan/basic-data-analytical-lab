# 🎯 风控监控仪表板 (Shiny App)

## 简介
本应用基于 `Shiny` 构建，旨在对 **玩家同桌关系** 与 **荷官获利** 数据进行可视化和风控分析，适用于电商、游戏等场景的异常检测。

## 功能模块
- **概览**：显示关键 KPI，分布图表。
- **玩家关系网络**：展示强同桌关系的网络图，支持缩放。
- **荷官获利异常**：散点图展示盈利与下注的关系，并自动列出异常组合（Z-score>3）。
- **风险评分**：计算综合风险分，列出 Top 50 高风险玩家对。
- **时间趋势**：展示每日新增同桌关系数的变化。

## 数据来源
应用内置了模拟数据，可直接运行。您也可以将真实的 CSV 文件放到 `data/` 目录，并修改 `global.R` 中的读取路径。

## 运行方式
1. 确保已安装 R 和以下包：`shiny`, `shinydashboard`, `data.table`, `ggplot2`, `plotly`, `DT`, `networkD3`, `dplyr`, `tidyr`。
2. 在 RStudio 中打开 `app.R`，点击 **Run App**。
3. 或在命令行中执行 `R -e "shiny::runApp('RiskDashboard')"`。

## 交互操作
- 可通过侧边栏的日期范围、风险阈值滑块进行筛选。
- 点击“刷新数据”可重新加载（若修改了数据源）。

## 自定义
- 若需替换数据，请修改 `global.R` 中的 `generate_data()` 函数，或直接读取外部 CSV。
