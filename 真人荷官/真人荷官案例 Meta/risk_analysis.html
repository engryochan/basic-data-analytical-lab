一、学术框架

采用三层顶级范式：

  1. 电商刷单检测：Support = same_round_count, Confidence = same_rate, Lift = same_rate / expected_rate
  2. 量化因子：same_rate = Correlation, profit_per_bet = PnL, roi_zscore = Alpha
  3. 图论：player_a-b 构成共现图，检测闭环团伙

六、最优化风控评分

RiskScore = 0.5Z(same_rate) + 0.3log(1+same_round_count)/max + 0.2*exp(-recency/7)

代码 
pair_stat[, z_rate := (same_rate - mean(same_rate))/sd(same_rate)]
pair_stat[, recency := as.numeric(Sys.Date() - as.Date(last_game_time))]
pair_stat[, risk_score_v2 := 0.5*z_rate + 0.3*log1p(same_round_count)/max(log1p(same_round_count)) + 0.2*exp(-recency/7)]
pair_stat[order(-risk_score_v2)][1:10, .(player_a, player_b, same_rate, same_round_count, risk_score_v2, risk_tier)]
